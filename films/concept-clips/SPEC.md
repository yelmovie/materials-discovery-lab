# 개념영상 SPEC · 「모루의 발견 극장」 (2026-11-09)

6번 프로젝트가 정한 A안 "실험 노트" 방식을 9 things 의 캐릭터(다람쥐 모루 + 공방 NPC 5)와 색으로 옮겼다. 10편 모두 같은 장면 부품(`kit.mjs`)을 쓰고 편별 데이터(`films.mjs`)만 다르다.

```text
GOAL:    활동을 마친 아이가 방금 한 실험을 15초 동안 다시 보고, 결론 한 줄을 자기 말로 말할 수 있다.
OUTPUT:  HyperFrames 0.9.26, 1920x1080 30fps 마스터 → 앱용 960x540 H.264(+faststart) / VP9 webm, 마지막 장면 WebP 포스터.
         앱 경로·파일명 그대로: public/assets/concepts/S01~S10.{mp4,webm,webp}. 편당 목표 300KB 이하(실제 150~220KB).
TIME:    편당 15.0 s (450 frames). 장면 경계 0 / 5 / 10 s = 앱의 '관찰하기·비교하기·기억하기' 버튼과 자막(cues) 경계.
LOOK:    바탕: 연구 노트 종이 #F7F4E6 + 연녹 모눈 48px (rgba(160,196,170,.42) 1px). 잉크 #214D43, 보조 글자 #3E6658.
         강조: 호박색 #D99A1E — 한 화면에 핵심 하나(기준선·결정적 이름표·도장 테두리). 글자는 강조색으로 쓰지 않는다(대비).
         결론 핵심 낱말: 형광 노랑 #FFE98A 배경(앱의 concept-keyword 와 같은 계열).
         글꼴: 나눔스퀘어 네오 400·700(게임과 같은 파일). 이름표 52/36px, 말풍선 50px, 결론 84px.
OBJECTS: 모루(companion.webp), 공방 NPC 얼굴(dandani·banguli·barami·tori), 우산·보관함·나무 시료 그림 — 모두 게임 안 그림을 그대로 씀.
         컵·물·시료 막대·누름판·전등·기포·휴지만 SVG 로 그림(게임 실험 화면과 같은 색: 고무 #E98981, 금속 #AAB7C8, 유리 #C6EAF3).
MOTION:  모루 등장 expo.out 0.6 s → 찌그러짐 0.12 s → back.out 복귀. 말풍선 back.out(1.4) 0.35 s, 퇴장 power3.in 0.22 s.
         이름표 = 지시선 0.22 s 먼저 → 카드 0.32 s back.out(1.6). 카메라 확대 1.06~1.08, power2.inOut 0.8 s.
         결론 = 낱말마다 blur 6px→0, 0.08 s 간격, 도착 후 정지. NPC 아래에서 올라옴 expo.out 0.5 s + 반응(찌그러짐).
         모루 한 번 뛰기(정답 순간 1회). 발견 도장 1.6→1 back.out(1.7), 마지막 2 s 이상 유지.
SOUND:   없음. 앱 플레이어가 muted 자동재생이라 소리를 넣어도 들리지 않는다(계획서 3-4).
BANNED:  어두운 바탕·네온·빛번짐·떠다니는 장식 입자, 보라/파랑 그라데이션, 유리 카드, 01/02 번호, 카드 세 장 나란히 동시 등장,
         모든 요소 동시 페이드업, 읽는 동안 움직이는 글자, 분자·입자 모형(교육과정 밖), 앱 자막과 같은 문장을 영상에 반복.
```

## 편별 장면표 (관찰 0–5 / 비교 5–10 / 기억 10–15)

| 편 | 0–5 s 질문·준비 | 5–10 s 실험 전·후 + 이름표 | 10–15 s 결론 · 반응 |
|---|---|---|---|
| S01 | "우산은 한 가지 재료로 만들었을까?" 천·살·손잡이에 점선 원 | 천(펼쳐지고 접혀)·금속(단단히 받쳐)·나무(잡기 좋아) 이름표 | 한 물체, **여러 재료** · 모루 |
| S02 | "어느 부품이 어떤 재료일까?" 부품을 2.2배 확대한 동그란 창 3개 | 관찰 카드가 먼저, 재료 이름이 나중에 찍힘 | 관찰한 특징이 **근거야** |
| S03 | "같은 힘으로 누르면 시료마다 다를까?" 고무·금속 + 같은 누름판 | 같은 힘으로 누름 → 고무만 눌렸다가 돌아옴, 금속 거의 그대로 | **조건은 같게**, 시료만 바꿔 · 단다니 |
| S04 | "관찰창에는 어떤 재료가 필요할까?" 창 강조 + 빛 시험(투명 시료 통과) | 모서리 강조 + 고무 누름 시험(돌아옴) | **성질을** 알면 쓰임이 보여 · 단다니 |
| S05 | "용기를 바꾸면 모양도 바뀔까?" 나무토막을 처음 컵에, 점선 윤곽 | 넓은 용기 → 길쭉한 용기로 옮김, 모양·크기 그대로 | 점선 윤곽을 겹쳐 보면 딱 맞음 · 고체는 모양과 크기가 **그대로** · 방울이 |
| S06 | "넓은 그릇에 옮기면 양이 줄까?" 처음 물 높이 기준선, 넓은 그릇으로 | 낮게 → 좁은 컵으로 옮기면 높게 | 처음 컵으로 돌아오면 기준선과 같아 · 모양은 달라도 **양은 같아** · 방울이 |
| S07 | "컵을 거꾸로 넣으면 휴지가 젖을까?" 마른 휴지를 컵 안쪽 위에 | 입구를 아래로 곧게 넣음, 물이 조금만 들어옴 | 공기·휴지는 말라 있어 · 공기도 **공간을** 차지해 · 바라미 |
| S08 | "공기가 나갈 길을 열면 어떻게 될까?" 같은 깊이 두 컵 | 배출구를 열면 기포가 나가고 물이 차오름 | 물이 들어와 / 공기 그대로 · 공기가 나가면 **물이 들어와** · 바라미 |
| S09 | "세 부분에 같은 재료를 써도 될까?" 몸체·창·모서리 점선 | 몸체(비를 막아)·창(안이 보여)·모서리(충격을 줄여) | 기록 ✓ 세 개 · **증거를** 모으면 발명이 돼 · 토리 |
| S10 | "세 시험을 모두 통과할까?" 비 ✓ / 나무 창이라 빛 ✗ / 충격 ✓ | 창을 투명한 재료로 고침(근거: 빛 시험 기록) | 같은 조건으로 다시: 세 시험 ✓ · 고치고 **다시 시험해** · 토리 · 도장 "발명 완성!" |

과학 확인: 시료 성질은 `docs/screen-spec.json` materials(유리·투명 플라스틱 transparent, 고무 cushioning, 나무 waterResistant=false)와 일치. S07 컵 안 물높이는 바깥보다 낮게(공기가 눌려도 남음), S08 은 컵 전체가 물속에 잠긴 상태에서 배출구로 기포가 나간다.
