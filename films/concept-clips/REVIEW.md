# REVIEW · 모루의 발견 극장 10편 (2026-11-09)

## 2026-11-12 과학 표현 수정

- S05는 용기만 바꾸어 옮긴 동일한 나무토막의 모양과 부피로 결론을 구체화했다. 토막이 용기 입구를 지나 이동하는 장면과 마지막 결론을 실제 렌더 프레임에서 확인했다.
- S10은 모서리의 누름판·눌림·복원과 재료 수정 뒤 같은 조건의 재시험을 보여 준다. 4.66초 누름, 5.15초 복원, 11.4초 재시험, 14.2초 결론을 확인했다.
- 두 편의 15초·30fps·960×540 무음 MP4·WebM과 포스터를 갱신하고 `public/assets/concepts/manifest.json`의 6개 해시를 실제 파일과 대조했다. 10개 활동의 과학 검토는 `docs/reviews/SCIENCE-REVIEW-20261112.md`에 이어 기록한다.

## 만든 결정
- 줄거리 세 가지를 따로 쓰지 않고 6번 프로젝트가 정한 A안(실험 노트: 질문 → 실험 재현 → 바뀐 곳 이름표 → 결론 한 줄 → 캐릭터 반응)을 그대로 옮겼다(BRIEF 4절). 대안이었던 "모루 일기장"(손글씨 일지)·"공방 뉴스"(앵커) 형식은 만들지 않았다.
- 길이 9 s → 15 s. 앱의 장면 버튼(관찰하기·비교하기·기억하기)과 자막 cue 가 5 s 마다 바뀌도록 영상 장면 경계를 0/5/10 s 로 맞췄다. 자막 문장(앱 DOM)과 같은 문장은 영상에 쓰지 않고, 영상에는 질문·이름표·결론 한 줄만 둔다.
- 게임 안 그림만 썼다(모루·공방 NPC 4·우산·보관함·나무 시료). 새 이미지 생성 0. 컵·물·시료·기포·전등만 SVG.
- 소리 없음: 앱 플레이어가 `muted` 자동재생이라 넣어도 들리지 않는다.
- 10편은 같은 부품(`kit.mjs`)과 편별 데이터(`films.mjs`)로 만든다. 그래서 HyperFrames 의 "장면마다 하위 컴포지션" 권장(경고 `nested_structure_needs_subcomposition`)을 따르지 않고 레이어 3개(종이·카메라·출연진)로 둔다 — 의도한 경고.
