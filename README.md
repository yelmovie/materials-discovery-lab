# 물질 공방 대작전

다섯 공방을 복구하며 재료·성질·고체·액체·공기를 탐구하고 보관함을 설계하는 교육게임 MVP야. 스테이지 선택은 2.5D 픽셀 RPG, 시설 안은 2D야. 기존 탐구10개에 적용 과제20문항을 더했고, 우산·보관함은 생성 기본 그림을 사용해 추후 GLB로 교체할 수 있게 했어.

## 실행

프로젝트 위치는 D:\iscreammedia_sc34\9 things야. Node.js와 npm이 준비된 환경에서 실행해.

~~~powershell
$env:TEMP = 'D:\DevTemp'
$env:TMP = 'D:\DevTemp'
npm ci
npm run dev -- --port 5189
~~~

기본 로컬 주소는 http://127.0.0.1:5189이야. 이미 node_modules가 있으면 설치를 생략할 수 있어. typecheck / test / build / preview 명령은 package.json에 정의되어 있어.

~~~powershell
npm run typecheck
npm test
npm run build
npm run preview -- --port 5190
~~~

## 구현 범위

- 지도에서 연구원과 동료가 길을 따라 이동하고, 공방 의뢰·실험·적용 과제·연구 기록·시설 복구로 이어져.
- 적용 과제는 선택·복수 근거·순서 구성·카드 분류 네 가지로 구성돼. 기본 탐구 뒤에 열리고 오답 관찰 안내를 제공해.
- 공통 홈·이전·소리·설정, 연구 수첩, 자동 저장, 시연 상태 분리, 보고·코어·엔딩·인증서·인쇄를 포함해.
- 설정의 교사용 도구에서 전체 해금 토글 하나로 시연해. 학생 진행·보상과 따로 진행하며 끄거나 새로고침하면 원래 학생 기록이 남아.
- 우산·보관함은 이번엔 2D 기본 그림이야. 실제3D 모델과 분리 부품 기준도8개는 후속 범위야.

## 저장과 납품 전 확인

학생 기록은 현재 브라우저의 material-workshop-mission.student.v1 키에 저장돼. 서버 동기화는 없어. 초기화는 확인 단계를 거쳐 이 게임의 기록만 지우고 소리 설정은 유지해. 다른 기기·브라우저에는 자동으로 이어지지 않아.

최종 검증 결과는 docs/reviews에서 확인해. 실제 태블릿·교실 네트워크·학생 사용성과 기존 제공 이미지의 상업 이용 근거는 사람의 확인이 남아 있어. 최신 검토는 [과학 학습 흐름](docs/reviews/SCIENCE-REVIEW-20261112.md), [공개 배포 검증](docs/reviews/RELEASE-REVIEW-20261112.md), [성적표](docs/reviews/SCORE-20261112.md)에 기록했어.

운영 주소는 https://materials-discovery-lab.yelsam.workers.dev/ 야. 운영·미리보기·localhost는 origin이 달라서 학생 저장 기록이 각각 분리돼. 같은 운영 주소의 업데이트는 기존 기록을 이어 읽어. 새 버전 안내가 나오면 모든 게임 탭을 닫고 다시 열면 돼.

Mac에서는 외장 SSD의 프로젝트에서 실행하고 임시파일과 캐시도 같은 SSD로 지정해.

~~~sh
mkdir -p .tmp/runtime .tmp/npm-cache .tmp/node-compile-cache
export TMPDIR="$PWD/.tmp/runtime" TMP="$PWD/.tmp/runtime" TEMP="$PWD/.tmp/runtime"
export npm_config_cache="$PWD/.tmp/npm-cache" NODE_COMPILE_CACHE="$PWD/.tmp/node-compile-cache"
npm test
npm run build
npm run preview -- --port 5320
~~~

브라우저 회귀 검사는 설치된 Python Playwright와 시스템 Chrome을 사용해. `tools/check-fit.py`는 실험·문제의 겹침과 스크롤, `tools/check-maker.py`는 제작 실패·수정·납품, `tools/check-delivery-pages.py`는 홈·팝업·마무리 페이지를 확인해. 프로덕션 빌드의 학생 완주는 먼저 `node tools/export-qa-reference.mjs`를 실행하고 `QA_REFERENCE="$PWD/.tmp/delivery-reference.json"`을 지정해 `tools/check-student-flow-fit.py`를 실행해. 정답 참조 데이터를 읽고 실제 화면의 버튼을 눌러 진행해.

원본65개와 샘플10장은 references에 보존돼. 이전 기획은 references/source-documents에 있고, 현재 구현 기준은 docs/PRD.md·TRD.md와 실제 도메인 데이터야.

배포 빌드는 서비스워커로 이미지·화면 코드·개념 영상·효과음을 사전 저장해. 미디어의 Range 요청도 캐시에서 처리해. 최초 온라인 준비 후 서버 중단 상태에서 지도·새 활동·관찰 저장·재로딩을 확인했어. 업데이트는 수업 중 강제로 갈아끼우지 않고 모든 게임 창을 닫은 뒤 적용해. [최종점검](docs/reviews/FINAL-CHECK-20261022.md)에 실측과 미검증 항목을 구분했어.

- **지도**: 화면 비율과 상관없이 위아래·좌우 띠 없이 꽉 채우고 연구원을 따라가. 이후 고도화 내용은 아래 ‘지도 이동 · 디자인 고도화’에 있어.
- **교사용 전체 해금**: 다섯 공방과 중앙 코어가 모두 열려. 활동 화면 왼쪽 아래 ◀ ▶ 와 키보드 ← → 로 14단계(활동10+보고·코어·복구·인증서)를 넘기고, 오른쪽 아래 ‘다음 스테이지’로 다음 공방 첫 활동에 바로 가. 낮은 가로 화면에서는 두 버튼이 상단 메뉴 줄로 올라가. 학생 기록은 그대로야.

## 지도 이동 · 디자인 고도화 (2026-11-07)

제작 현황 시트의 완료작 5개(우당탕 힘 실험실·동물기록 복구작전·초록정원 연구기지·생명시계 연구실·밀고 당기는 도시)의 지도를 직접 눌러 보고 공통 방식을 맞췄어.

- **길**: 그림에 칠해진 돌길을 다시 따서 `src/domain/worldMap.ts`의 길 데이터를 바꿨어. 문 앞 좌표도 실제 문에 맞췄어. 길 폭 안에서 움직이고, 길 가장자리를 밀면 미끄러지듯 따라가.
- **이동**: 방향판·방향키·WASD를 누르고 있으면 계속 걸어(대각선 포함). 땅이나 건물 이름을 누르면 길을 따라 걸어가고, 가는 길이 점선으로 보여. 문 앞에 닿으면 버튼이 ‘들어가기’로 바뀌고 벗어나면 돌아와.
- **카메라**: 지도 한눈에 보기, 손으로 둘러보기, 연구원 따라 보기를 넣었어. 공방에서 돌아오면 광장이 아니라 그 공방 문 앞에서 다시 시작해.
- **복구 연출**: 지도 전체가 어스름했다가 공방을 복구할수록 밝아져. 복구 직후에는 창문에 불이 켜지고 빛이 길을 따라 중앙 코어로 흘러가. 움직임 줄이기를 켜면 연출은 건너뛰어.
- **화면**: 이름표는 공방 친구 얼굴·잠금/완료 표시·활동 2칸 진행 점을 담은 간판으로 바꿨어. 위쪽에 다음 목표와 복구 수, 오른쪽 아래에 황금색 다음 행동 버튼이 있어. 다음 목표가 화면 밖이면 이름표가 가장자리에 붙어서 방향을 가리켜.

연구원·모루는 앞·왼쪽·오른쪽·뒤 네 방향 4프레임 걷기 그림을 써. 움직이는 쪽으로 방향이 바뀌고, 모루는 연구원이 걸은 길을 그대로 따라와. 시트는 `references/generated/walk`, 잘라 낸 프레임은 `public/assets/generated/walk`에 있고, `node scripts/prepare-walk-sprites.mjs`로 다시 만들 수 있어.

## 개념 영상 · 직접 조작 강화

각 활동에 15초 모션 영상 10개를 적용했어. 탐구→새 의뢰→개념 정리의 흐름, 다람쥐 모루의 단계별 힌트, 재료 카드 끌기와 분류, 고체·컵 직접 이동, 기울기와 연속 붓기, 공기 펌프, 재료에 따라 변하는 설계 모형을 포함해. 완료한 요구 조건과 예상은 접어 긴 패널을 줄였고, 의뢰의 주 버튼은 하단의 같은 자리에 있어.

Kenney의 CC0 효과음 8개와 Suno로 만든 배경음 2곡(메인 테마·파이널)을 사용해. 인물 목소리·영상이 나올 때 배경음은 작게 줄어. 제작·출처·재생성 방법은 [모션과 상호작용](docs/MOTION-AND-INTERACTION.md)에 정리했어.

```powershell
# 개발 서버를 켠 상태에서, Python Playwright + Chrome으로 점검
npm run check:layout
python tools/check-student-flow.py
# FFmpeg 경로는 FFMPEG 환경변수로 바꿀 수 있어.
npm run concepts:render
```

초기 화면 검수 기록은 docs/reviews/experience에 있어. 2026-11-12 최종 공개 검사는 9개 화면 크기의 실험·문제 180조합에서 실험과 조작 버튼의 스크롤·겹침·잘림이 없었어. 긴 설정·연구 수첩에는 읽기용 스크롤이 있어. 실제 태블릿·전자칠판의 터치 감도와 시청 거리는 실기기 검증이 남아 있어.

## 학습 흐름 간소화 · 디자인 정리 (2026-11-17)

버튼이 겹겹이 쌓여 지루하던 흐름을 "한 번 누르면 바로 반응"하는 방식으로 바꿨어. 핵심 개념을 고르는 순간(재료·성질·결론·예상)은 그대로 학생이 직접 고르게 남겼어.

- **새 의뢰(적용 과제 20개)**: 답을 고르거나 카드를 다 놓으면 바로 확인해. 맞히면 2초 뒤 다음 의뢰로 넘어가고, 틀리면 힌트가 바로 보여. ‘내 생각 확인하기’·‘다음 의뢰로’ 단계를 없앴어.
- **S01** 번호를 누르면 바로 관찰 기록. **S02** 재료 카드를 부품에 놓으면 1번 활동 관찰 기록을 근거로 바로 확인(드롭다운 제거).
- **S03** 실험 장면 위 ‘실험 시작’ 버튼이나 재료 카드를 누르면 바로 실험하고, 맞는 설명을 누르면 바로 기록돼. 다음 재료·시험은 자동으로 준비돼.
- **S04** 재료 카드를 놓으면 그 재료의 내 관찰 기록이 카드로 보이고, 필요한 성질만 눌러 결정해(드롭다운 2개 제거).
- **S05·S06** 예상은 대화상자 없이 오른쪽 첫 카드에서 바로 골라. S06은 ‘끝까지 붓기’ 한 번으로 한 용기를 다 옮겨(누르는 동안 붓기도 유지).
- **S07·S08** 컵 속 변화가 보이면 관찰 기록이 자동으로 남아.
- **S09** 부품 칸에 필요한 성질이 적혀 있고, 카드를 놓으면 내 관찰 기록이 근거로 바로 연결돼(체크박스 대화상자 2개 제거). 근거가 없는 재료는 시험실로 돌아가 기록을 더 모으게 했어.
- **S10** 시험 결과를 대화상자 없이 바로 읽어. **코어**는 레버만 밀면 세 부품이 차례로 연결돼.
- **중복 제거**: 탐구와 똑같은 S04 전시 상자·S10 최종 주문 제작을 뺐어. 주문 제작은 S02 지붕·S06 운반대·S08 바람개비처럼 새 상황에 쓰는 세 곳만 남았고, 활동 순서 줄에 ‘주문 제작’ 단계로 들어갔어.
- **개념 영상**: 다음 활동으로 넘어가는 버튼은 첫 장면(5초)을 본 뒤 열려. 다시 보기는 언제든 바로 닫을 수 있어.
- **자동재생**은 교사용 시연에서만 보여. 학생은 직접 조작해야 실험이 진행돼.
- **버그**: 1280×800 등에서 S05·S07 실험 장면 높이가 0이 되어 용기·컵이 안 보이던 문제를 고쳤어.
- **그림**: 재료 시료 6종 그림을 재료 카드와 S03 시료 재질(분홍 CSS 막대 → 실제 나무결·금속·유리 질감)에, 공방별 새 의뢰 그림 5장을 의뢰 카드에, 그림 실험대 배경을 S03·S05·S06·S07 실험 장면에 넣었어. 패널은 더 불투명하고 둥글게, 재료 카드는 둥근 받침 위에 올렸어.
- **화면 맞춤**: 주문 제작 단계가 들어간 S02·S06·S08에서 활동 순서 줄이 두 줄로 넘어가던 것과 S10 시험 버튼이 작던 것을 고쳤어. 아주 낮은 화면에서는 S10 실패 이유가 아래 힌트 줄에 바로 보여.

- **스테이지별 손동작**: 같은 버튼 누르기가 반복되지 않게 실험마다 손동작을 나눴어. S02는 재료 카드를 우산 그림의 번호 위로 직접 끌어 놓고, S03은 당기기=옆으로 밀기·빛=손전등 탭·물방울=스포이트 꾹·누르기=꾹 누르기, S05는 토막 끌기, S06은 기울여 붓기, S07은 컵 내리기, S08은 펌프 연타, S10은 비 시험=물뿌리개 꾹·빛 시험=스위치 밀기·누르기 시험=누름판 꾹. 모든 손동작은 Enter·Space로도 끝낼 수 있어.
- **CSS 그림 → GPT 그림**: S01·S02 우산(손으로 그린 SVG → 생성 그림), S04·S09·S10 보관함(재료 그림 재질), S07·S08 유리 수조, 코어 장치(소켓 3개가 레버에 맞춰 켜짐)를 바꿨어. 엔딩의 집 모양 아이콘은 공방 장치 그림 5장(차례로 켜지며 빛남)으로, 주문 제작 장치는 그린 작업대·별 받침대·나무 받침·바람개비로 바꾸고 지붕·받침 재료 칸에 천·플라스틱·고무·금속 질감을 입혔어. 컵 A/B·관 A/B처럼 겉모습으로 답이 보이면 안 되는 선택지는 그대로 단색이야.
- **디자인 체계**: 글자 크기 5단계·색·모서리·그림자·움직임 값을 토큰으로 묶고(`src/flow-polish.css`), 팝업은 금색 띠 머리·말풍선 대사·0.95→1 등장(움직임 줄이기 시 끔)으로 통일했어. 홈 버튼은 주 버튼 1개·보조 알약·텍스트 버튼 위계로 정리했어.
- **중복 정보 정리**: 힌트 줄과 같은 안내 문장, 진행 칩과 겹치는 숫자, 칸에 이미 적힌 필요한 성질 반복을 뺐어.

`tools/check-flow-clicks.py`는 새 학생 기록으로 홈부터 인증서까지 실제 버튼만 눌러 완주하고 활동별 탭 수를 `.tmp/flow-clicks/<크기>/report.json`에 남겨.

## S03 3D 시험 길 (2026-11-17)

성질 시험실의 S03 「직접 시험해 증거를 모아라」가 3D 시험 길로 열려. 연구원이 한 줄로 이어진 길을 걸으며 지정 시료 9개를 직접 시험해.

- **구역**: 누르기(발판에 뛰어올라 밟았다가 내려오기) → 당기기(버튼을 꾹 누르고 있기) → 비추기 → 적시기. 시험이 끝나면 설명 두 개 중 맞는 것을 고르고, 맞으면 기존과 같은 `실험:시료:standard` 기록이 남아. S04·S09는 그 기록을 그대로 읽어.
- **조작**: 왼쪽 아래 방향판, 오른쪽 아래 「점프」와 시험 버튼. 키보드는 방향키·WASD, Space(점프, 시험 도구 앞에서는 시험), E·Enter(시험).
- **결과**: 시료가 보여 주는 모습과 정답은 `model.ts`의 `resultFor`가 정해. 충돌 계산은 걷기와 점프에만 써. 고무 발판은 눌렸다가 돌아오기만 하고 연구원을 튕겨 올리지 않아.
- **실패가 없어**: 목숨·제한 시간·게임 오버가 없고, 방해꾼에 닿으면 움찔만 해. 같은 시료에서 세 번 틀리면 단단이가 볼 곳을 알려 줘.
- **기존 2D 화면**: 「기존 방식으로 하기」로 언제든 바꿀 수 있어(2D에서는 「3D 시험 길로 하기」). 움직임 줄이기, 교사용 전체 해금, 높이 500px 미만 화면, 탐구를 이미 마친 기록, WebGL을 쓸 수 없는 기기에서는 2D가 먼저 열려. 다른 재료 추가 시험과 자동재생은 2D 화면에 있어.
- **그림**: 연구원 걷기·재료 카드·단단이·지도 방해꾼은 기존 그림을 다시 썼고, 공방 벽 배경·수납장·바닥·재료 겉면 무늬 6종·연구원 동작(점프·당기기·기뻐하기)·소품(손전등·스포이트·고정 기둥·화분·유리병·상자)을 GPT 이미지로 새로 만들었어(`node scripts/prepare-run-stage.mjs`). 별 표시·점선 윤곽·빛·물방울처럼 정확해야 하는 것은 코드로 그려.
- **검사**: `node tools/check-run-stage.mjs <주소>`가 화면 버튼(1280×800)과 키보드(1024×768)로 끝까지 하고 저장 기록, 오답 처리, 새로고침, 화면 전환, S04 근거 표시를 확인해. 계획과 결과는 [3D 달리기 스테이지 계획](docs/RUN-STAGE-3D-PLAN-20261117.md)에 있어.

## 지도 공격 · 적용 의뢰 · 화면 균형 (2026-11-17 저녁)

- **지도 공격:** 공격 버튼이 손 도구 옆에 늘 보여. 악당 가까이 가면 보라색으로 커졌다 작아지며 눌러 달라고 알리고, 멀 때 누르면 "악당 가까이 걸어가서 공격해!"라고 안내해. 스페이스·J는 지도 버튼에 포커스가 남아 있어도 가까운 악당을 공격해. 원인은 병합 때 손 도구 버튼의 `data-map-hand` 표시가 빠져 공격 버튼이 붙을 자리를 못 찾은 것이었어. 순찰 중 사거리 경계에서 버튼이 깜빡이지 않게 현재 대상은 사거리를 30% 넉넉히 봐.
- **적용 의뢰 20개 점검:** 성취기준 [4과05-01~03]과 거리가 먼 문항 9개(관찰 순서 맞추기, 확인 자료 고르기, 보호대 충격 시험 순서, 연구자 태도, 발명 설명 등)를 바꿨어. 새 문항은 연필 부분의 재료 분류, 같은 재료(금속) 물체 고르기, 장화가 고무인 까닭, 관찰창 재료 고르기, 고체·액체 분류, 공기가 공간을 차지하는 예, 고체·액체·기체 정리, 비옷 재료, 자전거 부분과 성질이야. 남은 11개도 문장을 짧고 분명하게 다듬었어.
- **이전 기록 호환:** 바뀐 문항의 예전 답(`retiredChallengeIds`)은 불러올 때 빼고, 이미 마친 활동과 남은 문항 기록은 그대로 둬.
- **화면 균형:** 적용 의뢰 카드가 화면 위쪽에 작게 몰리고 아래가 비던 것을 가운데 정렬하고 글자·선택지를 화면 높이에 맞춰 키웠어(높이 640px 이상). S01·S02 오른쪽 패널은 우산 세 부분을 모두 보여 주는 관찰 수첩으로 바꿨고, 다른 활동의 오른쪽 패널은 내용 높이만 차지해 남는 자리에 배경 그림이 보이게 했어.
- **음악·영상 준비:** 수노 배경음(메인 테마·파이널) 프롬프트는 [docs/SUNO-BGM-PROMPTS.md](docs/SUNO-BGM-PROMPTS.md), 인트로·파이널 그림과 영상 프롬프트는 [docs/INTRO-FINALE-VIDEO-PROMPTS.md](docs/INTRO-FINALE-VIDEO-PROMPTS.md)에 있어.

## 성취 카드 (2026-11-18)

- **얻는 법:** 지도 악당(재료 바꿔치기 봇)을 세 번 맞혀 물리치면 화면 가운데에 성취 카드가 돌며 나타나. 「카드 보관함에 넣기」를 누르면 오른쪽 위 소리 버튼 앞 칸으로 날아가 채워지고, 칸을 누르면 보관함이 열려.
- **6장:** 공방 다섯 곳은 별 1~5개(브론즈·실버·골드·홀로·레전드), 중앙 코어의 마지막 악당은 ★ 칸의 「보너스」 카드야. 6장을 모으면 「컬렉션 완성!」이 나오고, 지도 피날레 영상은 카드를 닫은 뒤에 열려.

- **지도 멈춤:** 카드나 보관함이 열린 동안 앱 루트(`#root`)가 inert가 돼. 지도와 악당은 이걸 대화창이 열린 것처럼 보고 걷기·방향키·방향판·공격을 멈춰.
