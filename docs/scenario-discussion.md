# 물질 공방 대작전 장별 시나리오 대화안

작성일: 2026-10-14. 2026-10-15 사용자 승인으로 화면 방향을 확정했어. 아래는 시나리오 검토 기록이고, 현재 MVP 구현 기준은 [PRD](PRD.md)와 [TRD](TRD.md)를 따라.

## 기준 자료와 결정의 순서

[공유 대화 원문](https://chatgpt.com/share/6aced284-2754-83ec-aaf0-eb28b6344fd4)의 제목은 「9물체와 물질_3-2」야. 공개 페이지 본문 데이터를 직접 받아 설계 대화와 사용자의 후속 요청을 확인했어. 원문에서 확인되는 연결된 대화 ID도 6a87b083-3b40-83e8-af55-384afd0e9fd7로 일치해.

원문 텍스트 사본은 references/review/shared-conversation-transcript.md에 있어. 대화 속 과거 첨부파일 자체를 전부 다시 열람한 것은 아니고, 이번 폴더의 PRD·TRD·심화 설계·JSON·이미지·ZIP을 함께 검토했어.

결정 흐름은 다음과 같아.

1. 초반에는 재료 조사, 성질 실험, 상태 실험, 창고 분류, 발명을 제안했어.
2. 태블릿을 쓸 이유가 분명해야 한다는 요청에 따라 단순 분류를 줄이고 관찰·조작·비교·수정 과정을 강화했어.
3. 「물질 공방 대작전」이라는 제목과 5스테이지 × 2활동 = 10개 핵심 화면으로 정리했어. 별도 긴급 수리 단계는 마지막 발명·개선에 통합했어.
4. 공유 대화에서 01·02·09·10에 3D 물체 조사·분해·설계·시험을 적용하는 데 동의했어.
5. 심화 설계에는 증거 5종, 공방 복구, 역할이 있는 NPC, 연구 결과 보고, 코어 재가동, 엔딩과 인증서가 추가됐어.
6. 2026-10-15 승인으로 자연 맵만 2.5D 픽셀 RPG, 장소 내부는 2D 배경·UI, 01·02·09·10의 작업대 물체만 실제 3D로 확정했어.

## 이번 요청에서 확정된 화면 방향

- 메인: 제목·시작·이어하기가 있는 2D 화면.
- 스테이지 선택: 자연 속 공방 마을. 위에서 비스듬히 내려다보는 2.5D 픽셀아트와 이동하는 플레이어 캐릭터.
- 각 장소 내부: 기존 샘플 같은 2D 배경과 큰 실험 대상, CSS UI. 내부를 돌아다니는 RPG 맵으로 만들지 않아.
- 모든 화면 좌측 상단: 홈, 이전 화면 아이콘.
- 모든 화면 우측 상단: 소리, 설정 아이콘.
- 설정: 관리자 전체 해금 하나로 모든 장·활동·결과 화면에 접근. 장마다 나누어 해금하는 UI는 만들지 않아.
- 태블릿 가로형과 전자칠판을 고려해 핵심 안내와 조작 대상을 크게 표시해.

기존의 10개는 핵심 활동 화면 수로 유지하고, 이번에 요청한 메인·자연 맵은 공통 화면으로 더하는 안이야. 연구 결과 보고·코어 조작·인증서는 마지막 활동 이후 이어지는 패널로 묶을 수 있어.

## 내가 이해한 전체 이야기

생활 물체를 만드는 물질 공방의 코어가 멈췄어. 재료 기록이 뒤섞이고 실험 장치도 작동하지 않아. 학생은 신입 연구원이 되어 자연 속 마을의 다섯 공방을 찾아가고, 직접 조사하고 실험한 증거로 공방을 하나씩 복구해.

흐름: 메인 → 자연 맵 → 공방 입장 → 2개 활동 → 증거 획득 → 맵의 복구 변화 → 다음 공방. 5장을 마치면 연구 결과 보고 → 코어 재가동 → 엔딩·연구원 인증서로 이어져.

맵은 산책 자체에 시간을 많이 쓰게 하기보다 다음 의뢰와 복구 결과를 보여 주는 역할이야. 목적지 터치로 이동하고, 도착하면 해당 2D 활동 화면으로 전환하는 안을 추천해.

## 1장 재료 감정실

담당은 다람쥐 감정사 모루야. 재료 정보가 뒤섞인 우산을 조사하는 의뢰로 시작해.

- 01 물체 조사: 우산 전체와 천·살·손잡이를 살펴보고 확대해서 각 부분의 차이를 기록해. 2D라면 앞·뒤 보기와 부분 확대, 3D를 적용하면 직접 회전과 부품 선택을 제공해.
- 02 부품 판별: 부품을 벌려 살펴보고 재료 후보와 관찰 근거를 연결해. 이름만 고르면 끝나지 않고 근거가 필요해.
- 성공과 보상: 부품 재료 조사 기록을 얻고 재료 감정실의 간판·선반·코어 첫 구역이 켜져.
- 다음 장의 이유: 재료 이름을 알아냈으니 실제로 어떤 성질인지 시험해야 해.

우산은 천·금속 살·나무 손잡이로 기준을 통일했어. 천은 1장의 조사 재료이고, 2장의 기본 시료 5개 재료군과 구분해.

## 2장 성질 시험실

담당은 비버 시험관 단단이야. 사라진 물질의 성질 기록을 다시 만드는 의뢰야.

- 03 직접 시험: 고무를 당겼다가 놓고, 시료에 빛을 비추고, 표면을 확대하고, 같은 조건에서 두 시료를 비교해.
- 04 쓰임에 맞는 재료 선택: 안이 보여야 하는 창, 잘 잡히는 손잡이 등 요구 조건을 보고 필요한 성질 → 재료 → 앞서 얻은 증거 순서로 연결해.
- 성공과 보상: 성질 증거 카드가 연구 가방에 쌓이고 시험 도구와 공방 조명이 복구돼.
- 다음 장의 이유: 단단한 물체뿐 아니라 물과 공기를 다루는 장치도 고쳐야 해.

관찰 전에 성질 정답을 보여 주지 않아. 모든 플라스틱이나 금속의 성질을 하나로 단정하지 않고, 게임에 제시한 시료의 관찰 결과를 기록해.

## 3장 상태 실험실

담당은 물방울 연구원 방울이야. 모양과 양을 잘못 판단하는 이송 장치를 바로잡는 의뢰야.

- 05 고체 비교: 먼저 예상한 뒤 고체를 모양이 다른 용기 3개에 옮겨 봐. 전후 윤곽을 겹쳐 물체 자체의 모양과 크기를 비교해.
- 06 액체 비교: 컵을 직접 기울여 액체를 다른 용기로 옮기고, 처음 용기로 되돌려 기준선과 비교해. 높이가 달라지는 것과 양이 달라지는 것을 구분해.
- 추가 관찰: 모래도 부으면 전체 형태가 바뀌지만, 확대하면 각각의 알갱이는 고체임을 확인해.
- 성공과 보상: 고체·액체 비교 기록을 얻고 맵의 이송 배관에 물이 흐르기 시작해.
- 다음 장의 이유: 물의 이송은 해결했지만 보이지 않는 공기 장치가 아직 멈춰 있어.

여기는 녹고 어는 상태 변화 수업이 아니야. 실험용 액체는 흘리지 않는 조건으로 양을 보존하고, 원래 용기로 돌아왔을 때 비교가 성립하게 해. 고체를 용기에 맞추려고 자동으로 줄이거나 늘리지 않아.

## 4장 공기 추적실

담당은 구름·바람 형상의 바람이야. 비어 보이는 컵 안의 공기를 증거로 확인해.

- 07 닫힌 조건: 컵 안쪽 위에 마른 휴지를 고정하고, 컵을 수직으로 뒤집어 물속에 넣어. 컵 속 공기 공간, 들어온 물의 높이, 휴지가 젖는지 관찰해.
- 08 열린 조건: 공기가 빠져나가는 구멍이나 밸브를 열고 같은 깊이에서 비교해. 공기가 빠져나가며 물이 더 들어오는 과정을 보고 두 결과를 연결해.
- 생활 적용: 본편에서는 풍선이나 공기 주머니 중 하나만 간단히 연결하는 안을 추천해.
- 성공과 보상: 공기 이동 관측 기록을 얻고 펌프·환기팬이 움직여.
- 다음 장의 이유: 재료·성질·물과 공기의 기록을 이용해 실제 쓸 물체를 만들 차례야.

원자료의 “물휴지” 표현은 마른 휴지로 바로잡아야 해. 공기 보기 색은 공기가 차지한 공간을 알려 주는 표시이며 실제 색이 아니야. 입자 모형과 압력 수식은 넣지 않아. 물이 전혀 들어오지 않는다고 단정하는 연출도 피하고, 공기 공간이 남아 있는 모습을 보여 줘.

## 5장 발명 제작소

담당은 토끼 설계사 토리야. 앞서 모은 증거를 실제 물체 제작에 사용하는 마지막 의뢰야.

- 09 설계: “비를 맞아도 내용물을 보호하고 안이 보이는 보관함” 같은 의뢰 하나로 시작해. 쓰임 → 필요한 성질 → 부품별 재료 → 관찰 근거를 연결해.
- 10 시험·개선: 의뢰에 필요한 비·빛 등의 시험을 실행해. 실패하면 문제 부품과 관찰 결과를 확인하고 재료를 바꿔 다시 시험해.
- 성공과 보상: 설계도와 시험 기록을 얻고 생산 설비가 돌아가지만 코어는 마지막 확인을 기다려.
- 최종 연결: 증거 5종을 보고하고 핵심 부품의 재료와 성질을 확인한 뒤, 코어 레버를 직접 조작해 공방을 재가동해.
- 엔딩: 처음의 고장 난 공방과 복구된 공방을 비교하고 완성품·연구원 인증서·다시 설계를 보여 줘.

처음부터 조건에 맞게 설계했다면 바로 성공할 수 있어. 실패를 강제로 만들지 않아. 충격이나 공기 시험은 의뢰와 관련이 있을 때만 쓰고, 정확한 물리 해석 대신 교육용 판정 규칙을 설계해.

## 재미와 몰입을 높이는 우선 요소

1. 장을 끝낼 때마다 자연 맵의 물길·조명·팬·공방 외관이 달라져서 자신의 행동이 남게 해.
2. NPC가 장별 의뢰와 관찰 힌트를 맡고, 진행에 따라 대사가 바뀌게 해.
3. 증거 카드를 다음 장의 선택에 실제로 사용해. 수집만 하고 버리는 보상을 만들지 않아.
4. 정답을 알려 주기보다 다시 볼 부위 → 비교할 조건 → 최소 설명 순서로 힌트를 줘.
5. 최종 결과에 처음 설계와 개선 후 설계를 함께 보여 줘. 시간이 빠른 학생보다 근거를 사용한 과정을 보여 줘.

MVP에서는 다섯 장의 핵심 실험과 발명 한 종류, 맵 복구, 이어하기까지 구현해. 추가 의뢰·신소재 보너스·탐구 스타일 자동 분류·긴 영상은 후속 범위야. 기존 20~25초 Final Movie 대신 MVP에서는 게임 자산을 사용한 6~10초 복구 연출을 제공해.

## 공통 조작과 관리자 전체 해금

- 홈·뒤로·소리·설정은 메인, 맵, 활동, 결과, 엔딩에서 같은 위치를 유지해.
- 메인에서 뒤로 갈 곳이 없으면 아이콘은 보이되 비활성 처리해.
- 홈이나 이전 화면으로 나갔다 돌아와도 완료한 증거와 저장된 설계는 유지해.
- 음소거 상태는 화면이 바뀌어도 유지하고 소리 없이도 실험 결과를 알 수 있게 해.
- 드래그, 기울이기, 길게 당기기에 버튼·슬라이더 대체 조작을 제공해.
- 관리자 전체 해금은 하나의 선택으로 전 구간 접근을 허용해. 가짜 완료 기록이나 학생 증거 획득과는 분리해.
- 관리자 모드에서 후반 화면의 재료나 증거가 비어 막히지 않도록 시연용 자료를 제공하되, 실제 학습 기록으로 저장하지 않는 안이야.
- 전체 해금을 꺼도 실제로 완료한 진도는 사라지지 않아.

## 확정된 구현 기준

자연 맵만 2.5D 픽셀 RPG, 공방 내부는 2D 배경·UI, 우산과 발명품은 3D로 조작하는 구성이야. 상세 완료 조건과 관리자·저장 규칙은 [PRD](PRD.md), 구현 구조는 [TRD](TRD.md), 에셋 준비는 [ASSET-PLAN](ASSET-PLAN.md)에 정리했어.
