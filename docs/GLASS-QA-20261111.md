# 반투명 UI와 배치 점검 · 2026-11-11

버튼·상단 아이콘·도구 패널·읽기 창을 알파 배경으로 분리하고 텍스트 불투명도는 유지했다. 그림을 관찰하는 작업영역에는 약한 반투명 배경만 적용했다. 모바일 지도 시연 리본이 복구 버튼을 가리던 문제는 리본 위치/포인터 통과로 수정했다. 인쇄 시 종이 배경과 reduced-transparency 대안을 유지한다.

- 기존 최신 폰트 커밋 7bf8ad0 반영 후 수정. Node fs 테스트용 @types/node 누락을 보완.
- 48 단위 테스트 통과, TypeScript 및 Vite 빌드 통과.
- 1920×1080,1280×800,1024×768,915×412,390×844의 16경로 80상태 버튼 중심 가림·가로 넘침 검사. 모바일 지도 수정 뒤 재검사 이상 없음.
- 10개 활동의 의뢰/개념창 열기·닫기는 5해상도 50조합 확인. 통합 장시간 실행 중 모바일 경로 타임아웃은 분리 재실행 10개 모두 통과.
- 상태 해금이 포함된 브라우저 검사다. 모든 정답·오답 조합 자연 완주, 실물 태블릿, 다른 OS/Safari와 종이 인쇄는 미검증.

## 추가 카드·지도 조정
카드 반경18px와 기본 간격12px(짧은 화면8px)로 정리하고 과도한 패딩을 줄였다. 관찰 그림 영역과 터치 최소 크기는 유지했다.
초기 카메라 위치가 변하지 않을 때 늦게 표시된 UI와 표식 충돌 계산이 누락되던 현상을 수정, 250ms 간격으로 위치 검사를 갱신한다. 5해상도 지도 재검과 최종 80경로 검사 통과.
