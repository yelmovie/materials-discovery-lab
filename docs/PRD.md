# PRD — 물질 공방 대작전

버전 2.0 · 2026-10-22 · 실행 가능한 MVP 고도화 기준

## 1. 목표와 확정 범위

학생이 물체의 재료를 조사하고 물질의 성질을 같은 조건에서 비교한 뒤, 관찰한 근거로 보관함을 설계·시험·개선한다. **예상 → 조작 → 관찰 → 근거 → 새 상황에 적용**의 탐구를 완주하게 한다.

- 스테이지 선택만 2.5D 픽셀 RPG. 숲길을 따라 이동하는 연구원과 뒤따르는 모루를 보여 준다.
- 시설 안은 기존 2D 공방 그림과 2D 실험을 사용한다. 우산·보관함도 이번 MVP는 생성 기본 이미지로 표시하고, 후속에 같은 부품 ID의 GLB로 교체한다.
- 다섯 공방 × 두 활동 = 10개 활동. 기존 탐구에 **활동마다 적용 과제 두 문항, 총 20문항**을 더한다. 기본 탐구와 두 과제를 마쳐야 새 활동이 완료된다.
- 로그인·서버·실명 입력 없이 시작한다. 현재 브라우저에 진행을 저장한다.
- 공통 아이콘은 왼쪽 위 홈·이전, 오른쪽 위 소리·설정 네 개. 화면을 가로지르는 상·하단 장식 바를 두지 않는다.
- 설정의 교사용 도구에는 전체 해금 토글 하나를 둔다. 비밀번호나 활동별 바로가기 목록을 만들지 않는다.

목표 품질은 배포·납품 전 검토가 가능한 MVP다. 기능, 콘텐츠, 대상 기기 실측, 상업 이용 권리는 각각 검증한다. 문서의 목표가 실제 검증 결과를 대신하지 않는다.

## 2. 학습 목표와 평가 증거

주 사용 환경은 가로형 태블릿과 전자칠판이다. 아래는 기존 기획의 성취기준 연결과 게임 행동의 **요약**이다. 교사용 가이드의 기준 문장은 경기도교육청 자료 본문과 대조했으며, 아래에 검증 근거를 남겼어.

| 연결 기준 | 학생 행동 | 남기는 증거 |
|---|---|---|
| [4과05-01] | 물체의 부분·재료 구별, 같은 조건에서 성질 비교 | 우산 세 부분 기록, 시료별 관찰 카드, 쓰임과 성질 연결 |
| [4과05-02] | 고체·액체·기체의 성질 관찰·비교 | 예상, 용기 이동·복귀, 모래알 관찰, 같은 깊이의 컵 비교 |
| [4과05-03] | 쓰임에 맞는 물체 설계·시험·개선 | 부품별 재료·근거, 현재 설계의 세 시험 결과 |

게임만으로 성취기준 전체 달성을 판정하지 않는다. 교사의 발문·토론·실물 탐구·후속 평가와 함께 사용한다. 예상이 관찰과 달라도 감점하지 않으며 관찰 후 생각을 바꿀 수 있다.

## 3. 이야기와 보상

물질 코어 고장으로 다섯 공방의 재료 기록이 뒤섞였다. 학생은 신입 연구원이 되어 친구들의 의뢰를 해결한다. 첫 화면에서 무엇을 해야 하는지, 끝내면 무엇이 달라지는지 보여 준다.

시작 이야기 → 숲속 지도 → 의뢰 → 기본 탐구 → 적용 과제 → 연구 기록 → 시설 복구 → 다음 공방. 마지막에는 모은 근거로 자기 보관함을 완성하고 코어를 재가동한다.

| 시점 | 보상 | 학습과의 연결 |
|---|---|---|
| 직접 관찰 직후 | 관찰 카드·확인 표시 | 조사한 시료·조건·결과가 남는다 |
| 적용 과제 해결 | 발견한 원리의 짧은 피드백 | 새 쓰임에 배운 것을 적용한다 |
| 공방 완료 | 연구 기록 E01~E05·시설 복구 | 탐구가 세계의 문제를 해결한다 |
| 최종 시험 통과 | 자기 설계품·코어·인증서 | 성질을 이용해 설계한 성취를 보여 준다 |
| 재방문 | 다른 시료·허용되는 다른 재료 | 이미 얻은 기록을 빼앗지 않고 비교를 확장한다 |

속도 순위·연속 클릭·무작위 보상·실패 벌점은 넣지 않는다. 분량을 늘리기 위한 같은 문제의 단순 반복도 넣지 않는다.

## 4. 공방별 활동과 분량

| 공방 / 친구 | 기본 탐구 두 화면 | 적용 과제의 초점 | 기록 / 복구 |
|---|---|---|---|
| 1 재료 감정실 / 모루 | S01 우산 세 부분 관찰 / S02 부분·재료·근거 연결 | 하나의 물체와 여러 재료, 부분 기능 | E01 부품 재료 / 선반·간판 |
| 2 성질 시험실 / 단단이 | S03 당기기·빛·물방울·누르기 / S04 관찰창·보호대 의뢰 | 같은 조건 비교, 쓰임·성질·복수 해법 | E02 성질 증거 / 시험 장치 |
| 3 상태 실험실 / 방울이 | S05 고체를 세 용기로 이동 / S06 물 옮겨 복귀·모래 확대 | 모양·양, 물높이와 양 구별, 모래알 | E03 고체·액체 / 배관 |
| 4 공기 추적실 / 바람이 | S07 컵의 공기 공간 / S08 배출구 비교·주머니 | 빈 컵의 공기, 조건 통제, 공간 | E04 공기 관측 / 펌프·팬 |
| 5 발명 제작소 / 토리 | S09 성질·부품·재료·근거 설계 / S10 비·빛·충격 시험 | 기능별 재료, 관련 근거, 수정 후 재시험 | E05 설계도·시험 / 설비·코어 |

각 화면의 기본 탐구 후 적용 과제 두 문항을 연다. 오답에는 다시 볼 대상·조건·비교 위치를 안내하고 재시도를 허용한다. 문항·보기·피드백의 실제 데이터는 src/domain/challenges.ts가 기준이다. 실제 수업 시간이나 효과 향상 수치는 사용성 평가 전 확정하지 않는다.

## 5. 과학적 정확성

- 우산은 남색 천·금속 살과 봉·나무 손잡이로 통일한다. 천을 플라스틱으로 분류하지 않는다. 겉모습 하나로 모든 물질을 확정할 수 있다고 가르치지 않는다.
- 시료는 코팅하지 않은 나무·금속·투명 유리·투명/불투명 플라스틱·부드러운 고무를 구분한다. 모든 실제 제품이 같은 성질이라고 일반화하지 않는다.
- 비교할 때 도구·힘·물방울 양·조명을 유지하고 시료만 바꾼다. 실제 공학 성능의 수치 모형으로 설명하지 않는다.
- 고체를 용기에 넣기 위해 크기나 윤곽을 바꾸지 않는다. 액체는 흘리지 않는 조건에서 총량을 보존하며 처음 용기로 되돌려 비교한다. 다른 용기의 물높이만으로 양을 판정하지 않는다.
- 모래 더미의 흐름과 알갱이 하나의 형태 유지를 구별한다. 상태 변화·분자 모형·밀도·압력 계산으로 확장하지 않는다.
- 컵은 입구가 아래를 향하고 위에 휴지를 고정한다. 닫힘/열림은 같은 컵·방향·깊이에서 배출구만 바꾼다. 물이 절대 들어오지 않는다고 설명하지 않는다. 공기 보조 색은 위치 표시다.
- 보관함 선택 부품은 몸체·관찰창·보호대. 뚜껑은 몸체 연동, 손잡이는 고정이다. 크기·접합부는 통제하며 시료의 물 저항이 모든 제품의 방수를 보장하지 않는다.
- S09는 근거의 관련성과 최종 성공을 구분한다. 관련 근거가 있는 불리한 설계도 시험한다. 처음 성공한 학생에게 실패를 강제하지 않는다. 설계를 바꾸면 이전 시험 결과로 통과할 수 없다.

## 6. 지도와 다양한 조작

지도는 길을 따라 걷는 세계다. 다섯 건물·코어를 처음부터 보여 주고 다음 목적지를 이름표·행동 버튼으로 안내한다. 연구원이 이동하면 모루가 뒤따른다. 건물은 터치·키보드로 선택 가능하고 도착 후 입장한다. 잠긴 곳에는 필요한 앞선 기록을 설명한다.

시설에서는 부분 선택, 시료·도구 조합, 예상, 고체 옮기기, 누르며 붓기·기울기, 배출구 전환, 조건 비교, 부품 설계·시험을 사용한다. 필수 제스처는 탭·버튼·슬라이더로도 완료한다. NPC는 현재 할 한 가지 행동을 안내한다.

## 7. 디자인·설정·접근성

남색·청록·크림·따뜻한 금색을 기본으로 기존 배경·NPC·로고를 재사용한다. 지도·연구원·동료·핵심 물체는 생성 이미지를 쓴다. 정확한 아이콘·눈금·상태는 SVG·DOM으로 유지한다.

- 핵심 본문 18px 이상, 한글 어절 줄바꿈, 터치 영역 48×48px 이상. 정오답은 색과 문구·표시를 함께 제공한다.
- 1280×800·1024×768·1920×1080에서 대상·버튼이 가리지 않게 한다. 좁은 화면은 세로 스크롤을 허용한다.
- 설정 순서: 배경음·효과음 스위치 → 배경음 음량 → 시작 이야기 다시 보기 → 완료 후 엔딩·인증서 → 앱 정보 → 학생 가이드 → 교사 가이드·성취기준·전체 해금 → 저작권·출처 → 초기화·닫기.
- BGM 끄기 때 음량은 비활성화한다. 상단 소리는 전체 빠른 음소거다. 움직임 줄이기를 제공한다.
- 설정은 native dialog, Esc·포커스 복귀·배경 입력 차단을 제공한다. 초기화는 취소 우선 확인 단계로 진행·관찰·설계·보상·인증서 삭제를 구체적으로 알리고 소리 설정은 남긴다.

## 8. 저장·시연·최종 완료

관찰·예상·안정 체크포인트·적용 과제·설계·시험·완료·설정을 현재 브라우저에 저장한다. 조작 매 프레임 좌표는 저장하지 않는다. 저장 실패는 안내하고 다른 앱의 저장을 지우지 않는다. 이전 저장은 새 필드를 보완하되 기존 기록을 임의 삭제하지 않는다.

전체 해금은 메모리의 별도 시연 상태로 동작한다. 학생 완료·보상·인증서에 섞지 않는다. 해제하면 원래 학생 위치·진도로 돌아오고 새로고침하면 시연이 끝난다.

E01~E05에 따라 복구율은 20·40·60·80·95%가 된다. 다섯 기록과 현재 설계의 세 시험 성공 후 코어에서 보고 → 코어 조작 → 건너뛸 수 있는 짧은 복구 연출 → 인증서로 이어진다. 선택 별명 기본값은 신입 연구원이다. 시연 인증서는 학생 기록으로 저장하지 않는다.

## 9. 수용 기준과 남은 검증

정상 학생 흐름 10활동+20적용과제+최종 미션 완주, 저장 후 재개, 복수 설계·실패 후 수정, 액체 총량·공기 조건 보존, 시연 분리, 입력 대안, 화면별 가독성을 검증해 docs/reviews에 기록한다.

납품 전 실제 태블릿·교실 네트워크 실측, 교사·학생 사용성 평가, 교사의 콘텐츠 검토, 사용자 제공/생성 에셋의 상업 이용 근거가 필요하다. 미검증 상태를 10점 만점이나 상업 배포 승인 완료로 표현하지 않는다. ‘1우당타앙’ 원본 프로젝트는 이번 자료만으로 직접 비교 검증하지 않았다.

### 성취기준 원문 대조 기록

2026-10-22에 [경기도교육청 「초등 깊이있는 수업 프레임워크」 부록, 3~4학년군(2024)](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202411110127574203.pdf)의 PDF 77쪽(0-based 76) 본문에서 아래 세 기준과 해설을 직접 대조했어. src/settingsContent.ts의 세 문구와 일치해.

- [4과05-01] 물체를 이루는 여러 가지 물질의 성질을 비교하고, 물질의 종류에 따라 물체를 분류할 수 있다.
- [4과05-02] 물질의 세 가지 상태인 고체, 액체, 기체의 성질을 관찰하여 비교할 수 있다.
- [4과05-03] 다양한 물질의 성질을 이용하여 쓰임새 있는 물체를 설계할 수 있다.

기준 원문 대조와 학습효과 검증은 구분해. 이 게임만으로 기준 전체 달성을 판단하지 않고 수업·토론·실물 탐구·후속 평가와 함께 사용해.

## 12. 교실 연결 안정성과 검증 결과

프로덕션에서 서비스워커를 등록하고 정적 화면·그림·폰트를 처음 온라인 연결 때 준비한다. 최초 준비 전에는 인터넷이 필요하다. 이후 연결이 끊겨도 저장된 활동을 이어가고 새로고침할 수 있도록 한다. 수업 도중 새 버전으로 강제 교체하지 않고 모든 게임 창을 닫은 뒤 적용한다. 실제 학교 AP와 동시 접속은 납품 전 실측한다.

이번 검증은 docs/reviews/FINAL-CHECK-20261022.md가 기준이다. 서버를 종료한 조건에서 지도 복원, 새 활동 진입, 관찰 기록 저장·재로딩을 확인했다. 물리 Wi-Fi 단절·30명 동시 접속·학생의 실제 학습효과를 같은 결과로 간주하지 않는다.
