## 2. 보는 법

- **「맞음 / 고칠 것」 칸**: 줄마다 교사가 둘 중 하나를 고른다. (`☐ 맞음 ☐ 고칠 것` → `☑ 맞음` 또는 `☑ 고칠 것`)
- **메모 칸**: 고칠 것이면 고칠 방향을 적는다. 미리 적힌 「확인 필요」는 과학적으로 틀리거나 3~4학년에게 헷갈릴 수 있어 보여서 작성자가 표시한 것이다.
- **구분**
  - 탐구 질문: 직접 탐구 화면 안에서 학생이 고르는 질문
  - 관찰 문장: 탐구 화면에 나오는 설명·관찰 기록 문장 (고르는 문항 아님)
  - 제작 주문: 주민 주문품 만들기(S02·S06·S08). 부품 자리 하나가 한 줄
  - 새 의뢰: 탐구 뒤 적용 문항(활동마다 2개). 오답 피드백은 화면에서 **「다시 생각해 봐: 」** 뒤에, 정답 문장은 **「정답! 」** 뒤에 붙어 나온다
  - 모형 시험: S10 보관함 시험 결과 문장
  - 마무리 문장: 연구 보고서·코어·엔딩·인증서 문장
- **핵심 개념 문장**: 활동마다 개념 영상(`src/domain/concepts.ts`)과 정리 문장(`docs/screen-spec.json` → `learning.keyConcept`)을 문장마다 체크하게 따로 적었다.
- 분류(classify)·여러 개 고르기(multi)·순서(sequence) 문항은 정답 칸에 전체 짝을 적었다.

## 성질 시험실 (S03·S04) → 연구 기록 E02 「물질 성질 증거 묶음」

### S03 직접 시험해 증거를 모아라 · [4과05-01]

**학습 목표**
- 같은 조건에서 시료를 시험해 늘어남과 복원, 빛의 통과, 물의 스밈을 비교하고 결과를 기록할 수 있다.

**핵심 개념 문장**
- ☐ 맞음 ☐ 고칠 것 · 개념 영상 제목: 조건은 같게, 재료만 다르게
- ☐ 맞음 ☐ 고칠 것 · 영상 요약: 실험마다 재료만 바꾸고 다른 조건은 같게 해요.
- ☐ 맞음 ☐ 고칠 것 · 장면 1: 같은 도구로 서로 다른 시료를 비교해요.
- ☐ 맞음 ☐ 고칠 것 · 장면 2: 같은 힘으로 눌렀다 놓아 두 시료의 반응을 비교해요.
- ☐ 맞음 ☐ 고칠 것 · 장면 3: 빛, 물, 힘을 비교할 때는 실험마다 같은 조건을 지켜요.
- ☐ 맞음 ☐ 고칠 것 · 탐구 목표: 재료만 바꾸어 반응을 비교해요.
- ☐ 맞음 ☐ 고칠 것 · 관찰 포인트: 힘을 주기 전과 뒤, 빛을 비췄을 때의 표시, 물방울 자리를 봐요.
- ☐ 맞음 ☐ 고칠 것 · 정리 문장: 실험마다 비교할 재료만 바꿔요. 물의 양과 기다리는 시간처럼 다른 조건은 같게 해요.
- ☐ 맞음 ☐ 고칠 것 · 생각 질문: 물방울을 바로 본 기록과 한참 뒤에 본 기록을 그대로 비교해도 될까요?

탐구 질문 공통 사항 (`src/domain/model.ts` → `resultFor`, `src/screens/Activities.tsx`, `src/screens/SampleRunStage.tsx`)
- 질문은 `{시료}에서 본 것은?`이고 보기는 두 개(그 시료의 결과 / 반대 결과)다. 2D 화면과 3D 시험 길이 같은 문장을 쓴다.
- 오답 피드백: 2D는 `「다시 실험 보기」로 {보는 곳}을/를 한 번 더 보고 비교해요.`, 3D 시험 길은 `「다시 시험하기」로 {보는 곳}을/를 한 번 더 보고 비교해요.` 3D에서 같은 시료를 세 번 틀리면 아래 「3D 세 번 틀림」 문장이 단단이 그림과 함께 나온다.
