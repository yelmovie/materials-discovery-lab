# 개념 영상과 직접 조작 · 2026-10-22

다섯 공방의 활동 10개를 각각 9초 개념 클립과 연결했어. 탐구 뒤에 다시 볼 수 있고, 탐구와 적용 의뢰를 마친 완료 버튼에서는 개념 영상 → 다음 활동 또는 복구 보상으로 이어져. 영상은 건너뛰어도 학습 기록을 잃지 않아.

## 영상 구성

카메라: 과학 도형을 같은 크기로 비교하는 고정 정면/단면 구도. 카메라 이동 없이 대상의 이동과 변형을 보여 줘. 인물은 영상에 등장하지 않고, 기존 다람쥐 모루가 DOM 자막 옆에 일관된 모습으로 등장해. 마지막 1초에는 비교 결과를 유지해.

| 활동 | 0–3초: 관찰 | 3–6초: 변화 | 6–9초: 개념 고정 |
|---|---|---|---|
| S01 | 우산 전체 | 천·살·손잡이 분리 | 한 물체의 여러 재료 |
| S02 | 부품 벌려 보기 | 연결 관계 관찰 | 우산으로 다시 조립 |
| S03 | 같은 힘으로 두 시료 누르기 | 복원 차이 | 같은 조건의 비교 |
| S04 | 빛이 통과하는 창 | 모서리 보호대 변형 | 쓰임과 성질 연결 |
| S05 | 처음 컵의 나무토막 | 넓고 길쭉한 용기로 이동 | 같은 윤곽 유지 |
| S06 | 처음 컵 → 넓은 용기 | 넓은 용기 → 길쭉한 용기 | 처음 컵 기준선으로 복귀 |
| S07 | 뒤집힌 컵을 수직으로 넣기 | 컵 안 공기 공간 | 마른 휴지와 공기 공간 |
| S08 | 같은 방향·깊이의 컵 | 배출구에서 기포 방출 | 물이 공기 자리를 채움 |
| S09 | 부품과 창 분리 | 몸체·창·보호대 조립 | 증거에 따른 설계 |
| S10 | 같은 물로 비 시험 | 같은 빛으로 창 시험 | 모서리 시험과 완성 |

각 클립은 960×540, 24fps, 9초, 무음이야. 직접 작성한 SVG 도형을 sharp로 프레임 렌더링하고 FFmpeg의 H.264 MP4 / VP9 WebM 두 형식으로 인코딩했어. 마지막 프레임 WebP와 SHA-256 manifest도 함께 저장했어. 렌더 실행 파일은 배포하지 않아.

글자는 영상에 굽지 않고 `src/domain/concepts.ts`의 세 자막을 3초 간격으로 크게 표시해. 따라서 태블릿·전자칠판에서 자막 크기를 조정할 수 있어. 재생·일시 정지·이어서 보기·다시 보기·건너뛰기, 동작 줄이기 설정, 재생 거부와 파일 실패 대체 설명을 제공해. 닫을 때 재생과 소스 연결을 정리해. 영상이 열린 동안 게임 BGM과 효과음을 잠시 멈춰.

## 직접 조작

| 활동 | 화면에서 하는 일 | 다른 조작 방법 |
|---|---|---|
| S01 | 돋보기를 끌어 부분 확대 관찰 | 번호·부품 버튼과 확대 버튼 |
| S02 | 천·금속·나무를 부품 칸에 끌어 놓기 | 카드 → 놓을 칸 차례로 누르기 |
| S03 | 시료 변경 → 도구 작동 → 반응 관찰·기록 | 도구 버튼, 필수 비교 표시 |
| S04 | 쓰임에 맞는 재료를 창·보호대에 배치 | 카드와 칸을 순서대로 선택 |
| S05 | 나무토막을 세 용기로 끌어 옮기기 | 용기 또는 옮기기 버튼 |
| S06 | 기울기 조절, 누르는 동안 붓기, 총량 비교 | 조금씩 붓기 버튼 |
| S07 | 컵을 수직으로 끌어 물속에 넣기 | 컵 넣기 버튼 |
| S08 | 컵 배출구 열기, 기포 관찰, 펌프 3회 | 배출구·펌프 버튼 |
| S09 | 재료 조립 → 모형 색·투명도 변경 → 근거 연결 | 재료 선택창·부품 버튼 |
| S10 | 같은 조건의 세 시험 → 실패 원인 → 수정 | 시험별 버튼과 접을 수 있는 결과 |

적용 의뢰의 분류도 카드 끌기로 수행해. 키보드·터치에서 카드와 칸을 눌러도 같은 판정을 사용해. 선택, 관찰, 연결, 시험, 적용의 기존 정답 조건과 저장 스키마는 유지했어. 재료를 바꾸면 이전 설계의 시험 통과를 그대로 쓰지 않아.

모루는 지도에서 사람 연구원을 따라다니고, 활동의 같은 하단 위치에서 현재 진행에 맞는 힌트 3단계를 제공해. 힌트를 썼다고 보상을 깎지 않아.

## 소리와 출처

[Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), Kenney, CC0 1.0. 원본 ZIP은 `references/audio`, 원문 고지와 파일별 매핑은 `public/assets/audio/Kenney-CC0.txt`, `sources.json`에 보존했어. 클릭·놓기·발견·힌트·도구·붓기·공기·재시도 8종으로 구분했어. 이는 UI 피드백용 효과음이고 실제 물·공기의 현장 녹음은 아니야.

FFmpeg로 MP3 변환과 음량 정규화를 했어. 효과음은 동시에 하나만 재생하고, 숨은 탭에서는 음원을 멈춰. 배경 음악과 효과음 스위치는 분리돼 있고 헤더 소리 버튼은 둘 다 제어해. BGM은 기존 직접 합성 음악을 조용하게 유지해.

```powershell
$env:TEMP = 'D:\DevTemp'
$env:TMP = 'D:\DevTemp'
$env:FFMPEG = 'D:\Tools\ffmpeg\ffmpeg.exe'
npm run concepts:render
npm run dev -- --port 5189
# 다른 터미널에서 실행. Python Playwright와 Chrome 필요.
npm run check:layout
python tools/check-student-flow.py
```

기본 검수 프로필: 906×755, 1280×800, 1920×1080, 873×580 CSS 픽셀. 화면 전체 스크롤·버튼 가림·실제 터치 영역·팝업 중앙 위치를 측정하고, 숨겨진 details의 내용은 표시된 조작으로 세지 않아. 낮은 가로 화면에서는 긴 관찰 근거를 패널 안에서 스크롤할 수 있어. 실제 태블릿 손가락 조작·전자칠판 거리·학생 학습효과는 실기기와 수업에서 후속 확인할 항목이야.

검수 결과와 화면 캡처: `docs/reviews/experience/`. UI와 타입 점검에는 React 품질 점검 스킬의 훅·정리 함수·접근성·지연 로딩 항목을 적용했어.
