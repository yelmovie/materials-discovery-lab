# 우산·보관함 3D 관찰 모형 적용 계획 · 2026-11-21

설계서 「22. 3D 사용 기준」(Screen 01·02·09·10은 3D 적극 사용)과 `docs/3d-image-prompts.md`의 P0 후보를 실제로 적용한다. 모형은 Meshy로 만든 원본(`references/models/meshy-20261121/`)을 쓴다.

## 성공 조건

- S01: 우산을 손가락·마우스로 끌어 돌려 볼 수 있고, 아래쪽에서 천 안의 살·중심 봉을 볼 수 있다. 부품 번호를 누르면 그 부품이 3D에서 빛난다. 돋보기와 「부품 차례로 관찰」 자동 재생도 그대로 된다.
- S02: 재료 카드를 우산의 번호 위로 끌어 놓기가 그대로 된다(번호가 3D 부품 위치를 따라간다). 「부품 확대」 막대가 부품을 벌려 보여 준다.
- S09·S10: 재료를 바꾸면 몸체·관찰창·보호대의 색과 비침이 바로 바뀐다. 투명한 재료를 고른 관찰창만 안이 비친다. 비·빛·누르기 시험 표시가 그대로 나온다.
- 기록·판정·체크포인트 코드는 바꾸지 않는다. 모형은 보이는 방식만 바꾼다.
- WebGL이 없거나 모형을 못 불러오면 지금의 2D 그림으로 그대로 진행한다.
- 모형 하나당 내려받는 크기 1.5MB 안팎, 삼각형 4만 개 이하. three는 run-stage와 같은 청크를 나눠 쓴다.

## 하는 일

1. 원본 GLB를 텍스처 색과 위치로 부품별 메시로 나눈다(Blender 스크립트, `scripts/meshy/segment-parts.py`).
   - 우산: `canopy`(천) / `frame`(살·중심 봉) / `handle`(손잡이)
   - 보관함: `body` / `lid` / `window` / `handle`(손잡이·쇠붙이) / `bumper`
2. 텍스처를 1024px로 줄이고 gltfpack으로 면을 줄여 압축한다(`scripts/meshy/pack-parts.mjs`, 8번 방식). 결과는 `public/assets/models/`.
3. `src/game/ObjectModel3D.tsx`: three로 그리는 관찰 모형. 끌어서 돌리기, 부품 강조, 벌려 보기, 재료 색·비침, 부품 번호 위치 계산.
4. `src/game/ObjectViewport.tsx`: 3D가 준비되면 2D 그림 대신 3D를 보여 주고, 번호 위치를 3D에서 받은 값으로 쓴다.

## 지켜야 할 제한

- 3D 모형은 생성 그림으로 만든 학습용 모형이다. 실제 실험 증거로 쓰지 않는다.
- 재료를 바꿔도 모양은 그대로 두고 겉모습(색·비침·광택)만 바꾼다(`DesignModel`과 같은 원칙).
- 글자·번호는 3D에 넣지 않고 지금처럼 화면 버튼으로 둔다.

## 확인

- `npm test`, `npm run build`
- 브라우저에서 S01·S02·S09·S10을 실제로 조작(돌리기, 번호, 끌어 놓기, 재료 바꾸기, 시험)
- WebGL을 끈 경우 2D로 진행되는지
- 운영 주소 배포 뒤 모형 파일 응답 확인

## 구현 결과 (2026-11-21)

- 부품 나누기: `scripts/meshy/segment-parts.py`(Blender 5.2). 우산 천 137,739 / 살·봉 166,632 / 손잡이 10,869면, 보관함 몸체 501,656 / 뚜껑 40,317 / 창 34,159 / 손잡이·쇠붙이 84,305 / 보호대 52,887면으로 갈렸다. 색 미리보기로 경계를 확인했다.
- 줄이기: `scripts/meshy/pack-parts.mjs`(텍스처 1024·512px JPEG, `gltfpack@1.3.0` npx). `public/assets/models/umbrella.glb` 607,424B·31,505면, `box.glb` 734,784B·42,767면.
- 화면: `src/game/ObjectModel3D.tsx`·`object-model-3d.css`, `ObjectViewport.tsx` 연결. three는 달리기 화면과 같은 청크를 쓰고, 3D 보기 코드는 77KB(gzip 24KB)로 따로 늦게 불러온다.
- 재료 표현: 몸체·뚜껑은 몸체 재료, 창·보호대는 각 재료의 색(`sampleColors`)으로 칠하고 원래 텍스처는 명암만 남긴다. 투명 재료를 고른 창만 원래 유리 그림(안의 별)이 보인다. 금속이 어두워지지 않게 three 기본 실내 반사(RoomEnvironment)를 쓴다.
- 모서리 누르기 시험: 2D의 누름판 그림 대신 3D 누름판이 앞쪽 위 왼쪽 보호대를 누른다. 부드러운 고무면 조금 더 파고든다. 보호대가 한 메시라 모서리 하나만 찌그러뜨리지는 않는다.
- 확인: `npm test` 22파일 175개 통과, `npm run build` 통과. 개발 서버에서 S01(돌리기·번호·부품 빛남·관찰 기록), S02(부품 벌려 보기·끌어 놓을 번호 위치), S09(재료 바꾸면 창이 불투명 노랑으로), S10(누름판)을 시연 모드로 직접 조작했다.
- 남은 것: 학교 태블릿 실기기 속도. 권리 장부(`docs/RIGHTS-LEDGER-20261121.md`)의 3D 모형 줄 추가(다른 세션이 같은 파일을 고치는 중이라 미룸).
