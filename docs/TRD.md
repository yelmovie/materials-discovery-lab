버전 2.0 · 2026-10-22 · [PRD](PRD.md)의 MVP 구현 계약

## 1. 기술과 파일 책임

## 2. 상태·완료·적용 과제

React Context+reducer를 단일 학습 상태로 쓴다. 렌더러는 명령만 보내고 자체 완료나 localStorage를 만들지 않는다. route는 home/world/S01~S10, phase는 activity/report/core/ending/certificate다. 잠금·복구는 완료·연구 기록에서 계산하고 별도 해금 배열을 저장하지 않는다.

| 활동 | 기본 게이트 | 추가 게이트 |
|---|---|---|
| S01 / S02 | 세 부분 관찰 / 세 부분 재료·근거 | 각각 적용 두 문항 |
| S03 / S04 | 네 성질의 필수 시료 비교 / 두 의뢰 | 각각 적용 두 문항 |
| S05 / S06 | 예상+세 용기+결론 / 물 복귀+모래+결론 | 각각 적용 두 문항 |
| S07 / S08 | 닫힌 컵 기록 / 조건 비교+주머니 | 각각 적용 두 문항 |
| S09 / S10 | 요구·부품별 근거 / 현재 설계 세 시험 | 각각 적용 두 문항 |

기본 탐구 뒤 적용 과제를 연다. choice·multi(근거 복수 선택)·sequence(순서 구성)·classify(카드 분류) 네 입력을 사용한다. challengeResults:{id,answer[]}[]에 문항·보기의 안정 ID와 통과를 저장하고 화면상의 순번으로 정답을 판정하지 않는다. 오답·중복·다른 화면의 답을 통과로 처리하지 않는다. UI와 reducer는 같은 문항 데이터로 판정한다. 타이머는 화면을 떠나면 해제하고 시험 결과는 실행 당시 attemptId·revision이 같을 때만 반영한다.

구버전의 새 필드는 기본값으로 보완한다. 신규 과제가 없다는 이유로 기존 관찰·연구 기록을 버리지 않는다. 실제 필드와 마이그레이션은 storage.ts·테스트를 함께 확인한다.

## 3. 지도와 입력

래스터 2.5D 픽셀 배경 위에 스프라이트와 DOM 목적지 버튼을 배치한다. 실제 3D 카메라는 쓰지 않는다. 배경 크기와 공방 입구·길·초기 위치의 좌표계를 맞추며 그림을 교체하면 입구·길도 함께 검수한다.

- 목적지 탭·키보드·방향판은 같은 이동 상태를 쓴다. delta time으로 이동하고 비활성 탭 복귀 때 큰 delta를 제한한다.
- 길을 따라 입구까지 이동하고 도착 뒤 입장한다. 모달이나 탭 숨김 때 입력을 비운다.
- 연구원·모루의 발 위치로 크기·깊이를 맞춘다. 동료는 주인공의 이동을 뒤따른다.
- 목적지 이름표는 DOM 버튼, 접근성 이름·48px 터치 영역을 제공한다. 다음·잠김·복구 상태를 색과 문구로 구별한다.
- 복구 불빛은 기록에서 재계산하며 모션 감소 때 최종 상태를 빠르게 보여 준다.
- 언마운트 때 Phaser·이벤트·타이머를 해제한다. 왕복 후 중복 캔버스·핸들러가 쌓이지 않게 한다.

## 4. 실험의 불변식

시료 관찰 ID는 실험·시료·표준 조건을 구별한다. 표시 결과는 도메인에서 생성하고 다른 시료의 기록은 연결할 수 없다. 투명/불투명 플라스틱은 별개다.

고체는 용기와 무관하게 같은 크기·윤곽을 유지한다. 서로 다른 세 용기의 관찰만 누적하고 잘못된 드롭은 수를 늘리지 않는다.

액체 이동량은 요청량·출발 잔량·도착 여유 중 최솟값이다. 출발에서 뺀 양을 같은 업데이트에서 더한다. 음수·용량 초과·총량 변화가 없어야 한다. 처음 컵으로 복귀 전 양 비교 결론을 열지 않는다. 버튼·누르기·슬라이더는 같은 계산을 쓰고 떠나면 마지막 안정 단계로 복구한다.

공기 비교는 cupId·orientation·depth가 같고 ventOpen만 다르다. 닫힘의 공기 공간·마른 휴지와 열림의 기포·물 유입·젖은 휴지를 인과 순서대로 보인다. 색은 공기의 실제 색이 아닌 위치 보조다.

설계의 body/window/bumper는 재료와 관련 실험 근거를 갖는다. lid는 body와 연동하고 handle은 고정이다. 유리·투명 플라스틱 같은 복수 해법을 인정한다. 관련 근거가 있는 불리한 설계도 시험한다. 재료·근거 변경은 revision을 올리고 이전 시험을 현재 성공으로 쓰지 않는다.

최종은 E01~E05, 현재 attemptId·revision의 세 시험 성공, 보고를 검사한다. 새 설계 후에도 과거 인증서 기록은 보존한다.

## 5. 생성 이미지와 후속 GLB

기본 이미지는 umbrella.webp·invention.webp다. 이번에는 확대·부품 선택을 제공하며 실제 분리·회전·뒷면 관찰을 구현한 것으로 안내하지 않는다. 전용 뒷면 그림이 없으면 실제 뒷면을 본 것처럼 설명하지 않는다. 부품 설명·버튼은 아래 semantic ID를 유지한다.

| 대상 | 후속 노드 | 전환 조건 |
|---|---|---|
| 우산 | canopy/frame/handle | 조립 원점 공유, 천·금속·나무 구분, 벌림 offset 누적 금지 |
| 보관함 | body/lid/window/handle/bumper | 몸체·뚜껑 재질 연동, 창 두께·투명재질, 보호대 인스턴스 같은 의미 ID |

후속 GLB는 두 파일, 전체 20,000삼각형부터 시작하고 텍스처는 1024px를 기본으로 한다. 노드 계약·피벗·접합을 검사하고 실패 시 같은 학습의 2D 화면을 유지한다. 부품 기준 이미지는 메시 분리·조립 치수를 보장하지 않는다. GLB 완성은 이번 MVP와 별도다.

## 6. 설정·소리·저장·시연

설정은 native dialog의 showModal()로 열고 Esc·포커스 복귀·배경 차단을 제공한다. 문구는 별도 데이터로 관리한다. 전체 해금은 한 토글이며 학생 상태와 구별되는 메모리 demo를 사용한다. 시연은 학생 저장 경로에 쓰지 않고 해제·새로고침 후 학생 진행이 남는다.

저장 키는 material-workshop-mission.student.v1이다. known-field 화이트리스트·값 검증을 거친다. 손상·미래 버전·quota 오류를 안내하고 다른 앱 키를 지우지 않는다. 초기화는 이 게임 기록만 지우고 소리 설정은 남긴다.

오디오는 첫 포인터/키 입력 뒤 활성화한다. 배경음·효과음 스위치와 배경음 전용 음량을 제공한다. 빠른 음소거는 둘 다 끈다. 탭 숨김 때 반복 재생하지 않고 전환 때 루프가 겹치지 않게 정리한다. 현재 Web Audio 합성 소리는 녹음·AI 생성 음악과 구별해 출처를 적는다.

## 7. 자산·성능·검증

Phaser·무거운 모듈은 lazy load한다. 참고 이미지65개·샘플·프롬프트 캔버스는 필수 게임 로딩에 포함하지 않는다. 사용 이미지의 최적화본만 public/assets에 두고 원본·프롬프트·변환 매핑을 남긴다. 결과는 D: 프로젝트에 두고 개발 TEMP/TMP는 D:\DevTemp를 사용한다.

| 검증 | 수용 기준 |
|---|---|
| 학생 흐름 | 10활동·20적용과제·보고·코어·인증서 완주 |
| 과제 | 기본 전 차단, 오답 미통과, 중복 멱등, 저장 후 복구 |
| 과학 모델 | 액체 총량·상한·복귀, 공기 같은 조건, 고체 크기 |
| 설계 | 복수 정답, 실패→수정, 이전 시험 무효 |
| 교사 시연 | 전체 진입, 학생 무변경, 해제·새로고침 후 복귀 |
| 저장 | 이전 필드 보완, 손상·future·quota, 다른 키 보존 |
| UI·입력 | 1280×800·1024×768·1920×1080, 48px, 겹침·대안·모달 |
| 성능 | 초기 브라우저 로딩 실측·환경·캐시 기록, 왕복 후 리소스 정리 |

명령은 npm run dev / npm run typecheck / npm test / npm run build / npm run preview다. 존재하지 않는 E2E 명령을 실행 가능하다고 보고하지 않는다. 정적 테스트·브라우저·실기기를 구분하고 미확인은 NOT TESTED로 기록한다. 실제 결과는 docs/reviews와 CREDITS를 함께 본다.
## 13. 프로덕션 오프라인 계약

- src/services/offline.ts를 main.tsx에서 PROD에만 연결한다. 서비스워커 실패는 학습 앱 실행을 막지 않으며 짧은 상태 알림을 제공한다.
- npm run build 후 scripts/prepare-offline.mjs가 dist의 검토된 정적 파일 목록과 내용 hash 버전으로 sw.js를 생성한다. 현재34파일 약4.06MiB이며 개발 원본·샘플·학생 기록을 포함하지 않는다.
- HTML navigation은 network-first/4초 제한/index fallback, 정확한 정적 URL은 cache-first다. Vary:Origin 응답과 모듈 요청의 헤더 차이를 허용하기 위해 해당 whitelist 경로에서만 canonical URL+ignoreVary를 사용한다. API·타 출처·미등록 URL은 캐시에 넣지 않는다.
- skipWaiting을 자동 호출하지 않는다. 활성 수업을 유지하고 새 worker는 모든 게임 탭이 닫힌 뒤 적용한다. 이 앱의 이전 버전 캐시만 정리한다.
- manifest.webmanifest,192·512px 아이콘을 제공한다. 폰트 WOFF2·OFL 고지도 사전 저장 목록에 포함한다.
- 실제 서버 종료 후 새로고침·지도·새 S01·관찰 기록 복원을 확인했다. Node VM의 캐시 시뮬레이션과 실제 브라우저 재검증을 구분해 최종점검에 기록했다.
