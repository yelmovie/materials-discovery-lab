- `.tmp/linebreak-20261119/sweep.py`: `tools/check-experience.py`의 화면 순회(S01~S10 탐구·주문 제작·새 의뢰·풀이 후·개념 영상 창, 설정, 보고서·코어·엔딩·인증서, 지도, 홈과 시작 이야기 3장, 연구 수첩, 초기화 확인, NPC 의뢰 대화 5개)를 그대로 돌면서 화면마다 공통 `measure.js`를 실행. 같은 화면에서 공통 CSS 없이(before) 한 번, 공통 CSS를 끼운 상태(after)로 한 번 잰다. 1280×800·1920×1080, 화면 121장.
  - NPC 대사는 `aria-hidden` 표시층(`.workshop-visual`)에 그려지므로 이 층도 재도록 측정 범위를 넓혔다.
  - 지도 악당 말풍선은 직접 띄우기 어려워, 지도 화면에서 실제 `.map-encounter-say` 스타일로 악당 대사 30줄을 모두 띄워 쟀다.

## 고친 곳

- `src/korean-linebreak.css`: 공통 규칙 파일을 그대로 복사하고, 아래 「프로젝트 보정」 절에 세 줄을 더했다.
  - `.workshop-stage .workshop-line { text-wrap: balance; }`: NPC 대사가 다 나온 뒤 두 줄 길이를 고르게.
  - `.workshop-stage .workshop-line[aria-label="대사 모두 보기"] .workshop-visual { text-wrap: wrap; }`: 한 글자씩 나오는 동안은 줄이 출렁이지 않게 보통 줄바꿈(대사 버튼 이름이 「대사 모두 보기」인 동안이 치는 중). 글자가 다 나오는 순간 한 번만 고른 줄로 바뀐다.
  - `.map-encounter-say { text-wrap: balance; }`: 악당 말풍선.
- `index.html`: `<head>`에서 다른 스타일보다 먼저 `/src/korean-linebreak.css`를 링크. Vite가 묶은 `assets/index-*.css` 맨 앞에 들어가고, `scripts/prepare-offline.mjs`의 오프라인 목록은 `assets/*.css`를 모두 담으므로 따로 고칠 것이 없다.

## 남은 것·범위 밖

- 개념 영상 자막(영상에 구운 글)은 이번 범위 밖이라 재지 않았다.
- 캔버스 글: `ExperimentCanvas`의 Phaser 라벨은 `useAdvancedWrap`(낱말 단위)이라 낱말 안에서 끊기지 않는다. 줄 길이 균형은 재지 못했다.
- 보고서 제목 「관찰 기록을 모았어!<br/>이제 공방을 다시 움직이자.」의 `<br>`은 문장 단위로 끊어 둔 것이라 그대로 둔다.
- 악당 말풍선 「코어에 ‘바꿔치기 봇 전용’ / 이라고 쓰려 했는데!」: 닫는 따옴표 뒤에서 줄이 바뀐다(따옴표가 있어 `keep-all`이 끊기를 허용). CSS로는 못 막고 대사 문자열을 고쳐야 해서(음성 연결 대사와 같은 글) 이번에는 손대지 않았다.
- 성취 카드 보관함의 잠긴 카드 「악당을 물리치면 / 열려요」(14px, 글 상자 134px): 끝줄이 3자라 도구 기준에는 걸리지만 이미 `balance`가 고른 최선이고(끝줄 41%), 조건/결과로 뜻이 나뉘는 자리라 통과로 본다. 한 줄로 만들려면 글자 크기나 카드 폭을 바꿔야 해서 손대지 않았다.
