## 2. 중복 조작 전수 점검

홈 → 이야기 → 지도 → 활동 10개(탐구·주문 제작·새 의뢰) → 보고·코어·엔딩·인증서에서 보이는 조작 요소를 JS로 뽑아 비교했다(`report.json`의 `controls`).

| 화면 | 겹치던 것 | 처리 |
|---|---|---|
| 코어 재가동 | 「코어 레버」 밀기 막대와 「길게 눌러 코어 재가동」 버튼이 같은 일(레버 0→100%)을 함 | 밀기 막대를 없애고 주 버튼 하나만 남김. 안내 문장을 「아래 버튼을 길게 눌러 줘.」로 맞춤. 키보드는 버튼의 Enter·Space 길게 누르기로 그대로 |

점검했지만 그대로 둔 것(이유):

- 활동 위 「개념 보기」 단계와 마지막 주 버튼 「개념 보고 다음 활동」: 앞은 다시 보기(진행 안 함), 뒤는 다음 단계로 넘어감. 하는 일이 다르다.
- 우산·보관함 화면의 돋보기 끌기와 ＋/−/↺: 돋보기는 부분 확대 관찰, 버튼은 전체 크기와 키보드 접근용.
- S01·S10 「관찰 도움말」「시험 도움말」과 모루의 힌트: 도움말 안에 성취기준 관련 주의 문장(겉모습만으로 재료를 확정할 수 없음, 재료를 바꾸면 다시 시험)이 있다. 학습 문구라 옮기지 않았다.
- S03 2D 화면의 재료 카드 「바로 시험하기」와 손동작 버튼: 카드는 시료를 바꾸면서 시험, 손동작은 지금 시료 시험. 실험 흐름 설계(2026-11-17)라 유지.
- 의뢰 대화의 말풍선 누르기와 「이야기 더 듣기」: 글 버튼은 낮은 무게(text)로 이미 정리돼 있다.
- 설정의 「공방을 깨우는 이유 다시 보기」와 홈 「시작 이야기 보기」: 다른 화면에 하나씩.
