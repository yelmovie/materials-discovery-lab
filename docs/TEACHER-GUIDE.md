# 교사용 안내 · 물질 공방 대작전

## 1. 한 줄 소개

물질 공방을 다시 움직이기 위해, 물체의 재료와 성질을 직접 시험하고 기록해 보관함을 설계하는 과학 탐구 콘텐츠입니다.

## 2. 대상

- 학년·학기: 3~4학년군(학기는 저장소에 적혀 있지 않아 「확인 필요」)
- 과목: 과학
- 단원: 「확인 필요」(코드와 문서에 단원 이름이 없습니다)
- 성취기준(`src/settingsContent.ts`):
  - [4과05-01] 물체를 이루는 여러 가지 물질의 성질을 비교하고, 물질의 종류에 따라 물체를 분류할 수 있다.
  - [4과05-02] 물질의 세 가지 상태인 고체, 액체, 기체의 성질을 관찰하여 비교할 수 있다.
  - [4과05-03] 다양한 물질의 성질을 이용하여 쓰임새 있는 물체를 설계할 수 있다.
- 열 개 활동 모두 교사 검토 대기 상태입니다(`docs/screen-spec.json`). 검토표는 `docs/TEACHER-REVIEW-20261121.md`입니다.

## 3. 준비

- 기기: 태블릿, 전자칠판, PC의 웹 브라우저. 설계 기준은 가로 화면입니다(`docs/PRD.md`).
- 소리: 배경 음악, 효과음, 목소리를 설정에서 따로 끄고 켤 수 있습니다. 목소리를 꺼도 글과 말풍선은 그대로 나옵니다.
- 예상 시간: 「확인 필요」. 수업 시간은 사용성 평가 전에 확정하지 않는다고 `docs/PRD.md`에 적혀 있습니다. 성적표(`docs/reviews/SCORE-20261121.md`)는 학생 40분 수업을 아직 확인하지 못한 항목으로 남겨 두었습니다. 자동 검사가 새 기록으로 끝까지 누른 시간은 186초이며, 학생 수업 시간이 아닙니다.
- 인터넷은 처음 열 때 한 번 필요하고, 이후에는 미리 저장한 파일로 열립니다(`README.md`).

## 4. 차시 흐름

시작 이야기(토리의 초대) → 지도에서 공방 선택 → 활동 열 개(공방 다섯 곳, 곳마다 두 개) → 보고서·코어·엔딩 → 인증서

| 공방 | 활동 | 학생이 하는 일 | 배우는 개념 |
|---|---|---|---|
| 재료 감정실 | S01 | 우산을 부분별로 살펴보고 연필의 재료를 분류합니다 | 한 물체는 여러 재료로 이루어질 수 있습니다 |
| | S02 | 재료 카드를 우산 부품에 끌어 놓고 지붕 주문품을 만듭니다 | 관찰한 모습과 확인 자료를 함께 써서 재료를 설명합니다 |
| 성질 시험실 | S03 | 시료를 당기기·빛 비추기·물방울·누르기로 시험합니다 | 재료만 바꾸고 다른 조건은 같게 비교합니다 |
| | S04 | 관찰창과 모서리 보호대에 쓸 재료를 고릅니다 | 쓰임에 맞는 성질을 관찰 기록에서 찾습니다 |
| 상태 실험실 | S05 | 나무토막을 여러 용기로 옮겨 처음 점선과 비교합니다 | 고체는 용기가 바뀌어도 모양과 부피가 그대로입니다 |
| | S06 | 물을 옮겨 따르고 처음 컵의 기준선과 비교합니다. 모래알을 확대해 봅니다 | 흘리지 않은 물은 높이가 달라도 양이 같습니다. 모래알 하나는 고체입니다 |
| 공기 추적실 | S07 | 거꾸로 놓은 컵을 물속에 넣고 휴지를 관찰합니다 | 공기는 컵 안의 공간을 차지합니다 |
| | S08 | 컵의 배출구를 닫고 열어 비교하고, 공기 주머니를 관찰합니다 | 같은 조건에서 배출구만 바꿔 비교합니다 |
| 발명 제작소 | S09 | 보관함의 몸체·관찰창·보호대 재료를 고르고 근거 기록을 연결합니다 | 부품의 쓰임과 필요한 성질을 연결합니다 |
| | S10 | 비·빛·모서리 누르기 시험을 하고 고쳐서 다시 시험합니다 | 설계를 고치면 같은 조건으로 다시 시험합니다 |

활동마다 탐구 뒤에 새 의뢰 두 문항이 열립니다. 마지막에 개념 영상을 봅니다.

## 5. 정답과 판정 기준

- 전체 문항의 정답과 오답 피드백은 `docs/TEACHER-REVIEW-20261121.md`에 줄마다 있습니다. 아래는 핵심만 옮겼습니다.
- S03: 고무만 당긴 뒤 원래 모습으로 돌아옵니다. 투명 유리와 투명 플라스틱만 빛이 통과합니다.
- S04: 관찰창은 빛이 통과하는 재료(투명 유리 또는 투명 플라스틱), 보호대는 눌렸다가 돌아오는 재료(부드러운 고무)입니다.
- S05: 용기를 바꿔도 나무토막의 모양과 크기는 그대로입니다. S06: 처음 컵으로 돌아온 물의 양은 같고, 모래알 하나는 고체입니다.
- S07·S08: 컵 안의 공기가 공간을 차지해 물이 휴지까지 올라오지 못합니다. 배출구를 열면 공기가 나가고 물이 들어옵니다.
- S09: 필요한 관찰 기록이 모두 연결되었는지만 확인합니다. 재료가 맞는지는 S10에서 판정합니다.
- S10: 비 시험은 몸체가 모양을 유지하고 물이 스며들지 않아야 통과합니다. 빛 시험은 관찰창이 빛을 통과시켜야 하고, 모서리 시험은 보호대가 눌렸다 돌아와야 합니다.
- 어떤 재료든 필요한 성질과 관찰 근거가 맞으면 인정합니다(`src/settingsContent.ts` 교사용 안내).

## 6. 수업 팁

- 막히기 쉬운 곳: S06에서 높이가 달라지면 양도 달라졌다고 생각합니다. 처음 컵으로 되돌려 기준선과 비교하게 합니다. S03의 3D 시험 길에서 같은 시료를 세 번 틀리면 단단이가 볼 곳을 알려 줍니다.
- 되묻기 좋은 질문(`docs/screen-spec.json`):
  - 연필을 조사한다면 어느 부분부터 살펴볼까요?
  - 좁은 컵에서 높아진 물의 양을 어떤 방법으로 확인할까요?
  - 물방울을 바로 본 기록과 한참 뒤에 본 기록을 그대로 비교해도 될까요?
- 전체 수업: 전자칠판에서 한 단계씩 함께 읽고 학생의 선택 근거를 먼저 물어봅니다.
- 모둠 수업: 카드 끌기가 어려우면 카드와 놓을 칸을 차례로 눌러도 됩니다.
- 설정의 「교사용 도구」로 모든 단계를 한꺼번에 열 수 있습니다. 학생 기록은 만들지 않습니다.
- 가상 실험은 조건을 단순화한 모형입니다. 실제 시료 관찰과 토론, 후속 평가를 함께 하십시오.

## 7. 저장과 다시 하기

- 진행과 관찰 기록은 이 브라우저의 `material-workshop-mission.student.v1`에 자동 저장됩니다. 서버로 보내지 않고, 다른 기기와 다른 브라우저에는 이어지지 않습니다.
- 운영 주소, 미리보기, 로컬 주소는 저장 기록이 따로입니다.
- 처음부터 다시 하기: 시작 화면의 「새로 시작」 또는 설정의 「연구 기록 초기화」를 누르고, 확인 창에서 「연구 기록 지우기」를 누릅니다. 소리 설정은 남습니다.

## 8. 알려진 한계

- 학생 40분 수업과 학교 태블릿 실기기 속도는 확인하지 못했습니다(성적표, `docs/MESHY-3D-OBJECT-PLAN-20261121.md`).
- 3D 우산·보관함은 학습용 모형이며 실제 실험 증거가 아닙니다.
- 이 콘텐츠만으로 성취기준 전체를 달성했다고 판단하지 않습니다.
- 설정의 저작권 문구 일부가 현재 빌드와 다릅니다(`docs/RIGHTS-LEDGER-20261121.md`).
