## 외형과 등장

**재료 바꿔치기 봇 / 각진 목재·금속 몸통, 축 늘어진 천과 과장된 청록 물방울.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

57px 정적 재시안에서 큰 물방울을 확인했다. 양쪽 자세와 실제 이동 중 검증은 남았다. 천 끝 아래 외곽선 있는 물방울 하나가 두 방향에서 읽히는지 1:1 무문구로 확인한다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 재료 감정실 | 금속판을 빼고 천으로 바꿔 끼우기 | “반짝이는 판은 내가 챙겼어!” |
| 성질 시험실 | 젖은 천을 한 번 꾹 짜기 | “이 천에서 물이 뚝뚝!” |
| 상태 실험실 | 고체·액체 모형 표지를 홱 뒤집기 | “이 표지는 반대로 꽂아야지!” |
| 공기 추적실 | 얇은 천으로 송풍구 가리기 | “여기도 천으로 막아 볼까?” |
| 발명 제작소 | 맞는 조립 판을 등 뒤로 숨기기 | “부품이 하나 모자라지?” |
| 중앙 코어(선택) | 고정 덮개를 옆으로 밀기 | “이 덮개는 내가 잡고 있을래!” |

상황 대사 예시:

- 접근: “은색 판은 내 거야!” / “천 한 장이면 됐지 뭐!”
- 1·2타: “앗, 판이 휘청했어!” / “천 아래 물이 뚝뚝!”
- 퇴장: “상자처럼 접혀 버렸네!” / “판은 돌려주고 갈게!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 네모난 판 모서리에 도장 찍히듯 한 번 |
| 2타 · 더 큰 반동 | 천이 펄럭이고 청록 방울 한 개가 튐 |
| 3타 · 마무리와 퇴장 | 접히는 상자처럼 악당이 납작해지며 소품이 내려감 |
| 주인공 접촉 | 주인공은 팔로 물방울을 막으며 한 발 미끄러짐 |
| 보조 캐릭터 접촉 | 동료는 두 앞발을 들고 퐁 튄 뒤 착지 |
| 악당의 접촉 공격 동작 | 젖은 천을 짧게 잡아당겨 툭 털어냄. 물방울은 가독성을 위해 한 개만 크게. |
| 타격·퇴장 효과음의 차이 | 탁 → 톡톡 → 접히는 바스락 |
| 접촉 효과음 모티프 | 판 ‘탁’, 물 ‘톡’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 몸은 좌·우 모두에서 주인공을 향하게 한다. 천은 손 접점에 붙이고 큰 물방울은 두 자세 모두 천 끝 바로 아래로 떨어지게 그린다. 축소했을 때 물방울이 몸 뒤에 묻히면 좌우 프레임을 따로 그려 빈 공간을 확보한다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/domain/worldMap.ts](../src/domain/worldMap.ts) · [src/domain/model.ts](../src/domain/model.ts) · [src/domain/challenges.ts](../src/domain/challenges.ts). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 1:1에서 천 아래 물방울이 보여야 다음 단계로 간다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
