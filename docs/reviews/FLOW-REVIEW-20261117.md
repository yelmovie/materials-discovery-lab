## 추가 반영 (같은 날)

- 옵시디언 「과학34 공통 — 11월에 추가된 방식」의 힌트 3단계 원칙에 맞춰, 오답 뒤 안내가 남은 선택지를 가리키지 않게 고쳤다(S03 ‘다른 설명을 골라 봐요’ → ‘다시 실험 보기로 ○○을 한 번 더 보고 비교해요’).
- 스테이지별 손동작(밀기·꾹 누르기·탭·그림 위로 끌기), CSS 그림의 GPT 그림 교체, 팝업·글자·색 토큰 정리. 자세한 목록은 README.
- 학생 화면의 자동재생은 이 시리즈 공통 방식(‘직접 해보기’)과 다르게 교사용 시연에서만 보이게 했다. 핵심 실험을 대신 진행해 개념이 지나가 버리기 때문이다.

## 확인

- `tools/check-flow-clicks.py`: 새 학생 기록으로 홈→인증서까지 실제 손동작(탭·끌기·꾹 누르기·밀기)만으로 완주. 1280×800·1024×768·915×412·844×390 모두 통과, 191탭. 개념 영상은 첫 장면 전에 넘길 수 없음을 확인.
- 이전 흐름의 같은 경로는 코드 기준 추정 약 310탭(새 의뢰 30, S03 26, S04 15, S06 13, S09 10, S10 9 등 줄임). 추정치이며 이전 코드로 측정한 값은 아니다.
- `tools/check-fit.py` 7개 화면 크기 × 10활동 × 탐구·의뢰 140화면: 겹침·잘림·스크롤·작은 터치 대상·콘솔 오류 0건(`fit-20261108/flow-20261117-release/layout-report.json`). 같은 날 원래 코드로 돌린 기준(`flow-baseline`)에서는 S08·S10이 이미 실패했었다. 코어 화면(844×390)은 완주 검사로 따로 확인했다.
- 검사 중 개발 서버의 핫 리로드가 화면 상태를 초기화해 생긴 실패는 코드를 건드리지 않고 다시 돌려 통과를 확인했다.
- 실제 태블릿 터치감, 교실 화면 거리, 학생 반응은 확인하지 못했다. 엔딩 아이콘과 주문 제작 장치도 같은 날 GPT 그림으로 바꿨다(아래).
