# 최종점검 — 물질 공방 대작전

작성일: 2026-10-22 · final-check / design / iscream-settings 적용

## 판정: 상업 배포 보류 · 실행 가능한 MVP 완성

기능·학습 설계·디자인을 구현하고 테스트했지만, 사용자 제공 이미지의 상업 이용 근거와 실제 학생·학교 기기 검증은 남아 있다. **10점 만점 완료나 납품 승인으로 표현하지 않는다.** 공개 배포는 수행하지 않았다.

목표는 사용자가 요청한 10/10 품질이다. 아래는 스킬 규격인 11점 척도(10=기준 충족, 11=근거가 있는 기대 초과)로 평가했다. 관찰 가능한 20항목 **182/220**, 영상 1항목 N/A, 2항목 측정 불가다. 전체 253점 환산·종합 만점 선언은 하지 않는다. 학생의 실제 학습효과와 재미를 입증한 실험 결과가 아니라 MVP의 설계·구현 점검이다.

## 구현 결과

- 지도만 생성 그림 기반 2.5D 픽셀 RPG. 연구원·모루가 실제 문 좌표까지 길을 따라 이동한다. 시설 안은 2D 배경·물체·동적 실험이다.
- 기존 배경5·NPC5·로고를 활용하고 지도·연구원·동료·우산·보관함 기본 그림5개를 생성·적용했다. 원본은 references/generated, 배포용은 public/assets/generated에 보존했다.
- 기본 탐구10개에 적용20문항을 추가했다. 선택·복수 근거·순서 배열·분류가 있으며, 기본 탐구와 두 과제를 모두 마쳐야 새 완료·보상을 받는다.
- 홈/이전/소리/설정 SVG, 독립 음악·효과음 스위치, BGM 음량, 학생·교사 가이드, 성취기준·저작권, 확인 후 초기화, 시연 전체 해금 토글을 구현했다.
- 시연은 메모리 복사본에서 예시 기록을 사용하며 학생 저장에 섞이지 않는다. 설정 안에 개별 페이지 바로가기 목록을 넣지 않았다.
- PRD·TRD v2, 이미지·3D 프롬프트 Markdown/JSON/독립 HTML 캔버스와 별도 Page를 작성했다.

## 실행 검증

- npm test: 2개 파일 **28개 통과**. 전체 진행, 추가 과제 게이트·잘못된 답, 양 보존, 공기 비교, 복수 설계·실패·수정, 현재 설계 판정, 구버전 저장·손상·미래 버전, 시연 분리를 포함한다.
- npm run build: 타입 검사·Vite 빌드·SW 구문·사전 저장 경로 검증 통과.
- 빌드 경고: Phaser 청크 약1.21MB(minified), gzip 약332KB. 실패가 아니며 지도·실험 진입 때 지연 로드한다.
- 오프라인: 정적34파일 약4.06MiB를 미리 저장. 전체 준비의 단순 상한 환산은 30명 약122MiB다. 실제 최초 화면 전송량·학교 AP 대기시간과 동일한 측정값이 아니다.
- 실제 서버 중단에서 HTML만 복구되던 문제를 재현했다. 정적 응답 Vary:Origin 때문에 모듈 요청이 캐시를 놓치는 경로를 고쳤다. 정확한 정적 URL에만 ignoreVary를 적용하며 API·외부 요청은 캐시하지 않는다.
- 수정 후 새5190 환경에서 준비 완료→서버 Ctrl+C→HTTP 연결 거부 확인→지도 reload→새 S01 진입→관찰 기록→다시 reload의 복원을 확인했다.
- HTML 캔버스에서 MVP 필터가5개만 표시되고, 화면 안의 지도·연구원·모루 미리보기 로드가 정상임을 확인했다. Markdown/JSON/HTML과 별도 Page에 제작 목록을 보존했다.

## 남은 납품 조건

1. 제공 배경·NPC·로고와 생성 이미지의 상업 이용 근거를 제작자가 확인·보관한다.
2. 실제 학생으로 동기 이해·읽기 수준·완주 시간·오개념·자발적 재도전을 관찰한다.
3. 실제 태블릿/전자칠판, 전10화면 정상 UI 완주, 음향 청취, 학교망 첫 접속·30명 동시 접속을 검증한다.
4. 3D 교체는 우산 S01·02와 보관함 S09·10이 우선이다. 이번 MVP에 GLB를 생성·적용한 것으로 표시하지 않는다.
