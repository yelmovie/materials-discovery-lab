# 실험 화면 확대·중복 안내 정리·배속 자동재생

2026-11-08 기준. 기존 화면 맞춤과 자동재생을 확장했다. 저장 스키마, 해금 규칙, 정답 판정, 기존 학습 기록은 유지한다.

## 반영 내용

- 가로 화면에서 실험 영역을 약 70%까지 넓히고 조작 패널의 폭을 제한했다. 작은 가로·세로 화면에서도 그림과 조작 버튼을 같은 화면에 배치한다.
- 자동재생에 0.5·1·1.5·2배속을 추가했다. 재생 중 변경은 현재 대기 시간부터 반영하며, 활동을 바꿔도 선택한 배속을 유지한다. 배속은 실행 중인 앱 안에서만 기억하고 학생 저장 파일에는 추가하지 않는다.
- 실험 대기 시간과 주요 그림 전환에 배속을 적용한다. S03의 별도 완료 타이머가 자동재생 속도와 어긋나지 않도록 자동재생이 실험 완료 시점을 관리한다.
- S06은 물 이동을 마친 뒤 학생이 결론을 고르면 모래알 확대 관찰도 자동재생으로 실행할 수 있다.
- 재료·근거를 고르는 S02·S04·S09는 직접 선택한다. S03 관찰 문장, S05·S06 결론, S08 조건 비교, 적용 문제의 답을 자동으로 선택하거나 제출하지 않는다.
- 직접 조작, 명시적인 중단, 활동 전환, 탭 숨김에서 자동재생을 중단하고 대기 타이머를 정리한다.
- 현재 상태에 맞는 다음 행동을 하단 한 곳에서 안내하고, 기록·결론 선택·다음 단계 등 현재 필요한 조작을 강조한다.
- 실험 그림과 선택지에 반복되던 결과 문장, 조작법과 공기 실험의 중복 설명을 정리했다.
- 세로 화면의 마지막 시험 버튼은 세 시험을 나란히 배치했다. 설계에서 시험실로 돌아온 경우에만 보이는 복귀 버튼이 단계 메뉴에 가려지던 문제도 수정했다.

## 수정 파일과 범위

- `src/components/ExperimentPlayback.tsx`, `experiment-playback.css`: 배속 선택, 진행 중 속도 반영, 탭 숨김 중단.
- `src/screens/Activities.tsx`: 상태별 행동 안내·강조, 직접 선택과 자동 관찰의 경계, 시료 완료 시점과 모래 자동 관찰.
- `src/stage-fit.css`: 실험 확대, 작은 화면 조작 배치, 복귀 버튼 가림 수정, 배속 애니메이션.
- `src/game/ExperimentCanvas.tsx`: 반복 결과 설명을 제거하고 간결한 실험 상태 표시.
- `tools/check-playback-speed.py`: 실제 배속과 취소 동작 회귀 검사.
- `tools/check-student-flow-fit.py`: 모래 자동 관찰 뒤 결론을 학생이 직접 고르는 경로 검증.
- `graphify-out/`: 드라이브 공통 지침에 따라 AST 그래프 갱신.

추가 의존성은 없다. 배포는 수행하지 않았다. 기존 Phaser 청크 크기 경고는 남아 있지만 빌드는 정상 완료했다. 실제 iPad·Android 터치와 Safari는 미실측이며, 위 결과는 Chrome의 실제 브라우저 화면 크기를 바꿔 확인한 결과다. 낮은 가로 화면의 교사용 시연에서는 중복 완료 안내 줄을 숨겨 실험 공간을 확보하고, 조작 버튼과 다음 단계 버튼을 유지한다.

직접 생성한 원본 보관본, 브라우저 프로필, 임시 파일, 검사 로그, 스크린샷과 빌드 파일은 확인한 외장 T7 SSD에 저장했다. 앱 자체의 채팅 자동 저장 경로를 변경했다는 의미는 아니다.
