# 9 things · 물질 공방 대작전 개선

대상: `/Volumes/T7 Shield/iscreammedia_sc34/9 things`. 1~5번 원본 수정 없음. 커밋·배포 없음. 현재 폴더는 Git 저장소가 아니므로 커밋 기준 전후가 아니라 이번 수정 직전 코드와 이후 실행 증거를 비교한다.

## 실제 적용

1. 고체·액체 첫 예상과 현재 생각을 별도 보존한다. 현재 답을 바꿔도 처음 예상은 남으며, 활동 패널과 연구 수첩 양쪽에서 확인한다. 구버전 기록은 존재하지 않던 최초 답을 만들어 넣지 않는다. 교사용 시연도 별도 예시 최초 예상으로 동작한다.
2. 여러 창이 같은 저장 슬롯을 사용할 때 마지막으로 읽은 원문과 비교한다. 외부 변경/삭제를 감지하면 해당 창의 자동 저장을 멈추고 새로고침 안내를 표시한다. 더 새로운 기록을 오래된 창이 덮어쓰지 않는다. 이는 동기적 비교와 storage 이벤트를 이용한 최선의 충돌 방어이며, 완전 동시 쓰기를 원자적으로 직렬화하는 데이터베이스는 아니다.
3. 짧은 가로 915×412에서 카드 내부 live-region이 문서 크기를 늘리는 문제를 부모 위치 기준으로 수정했다. 중앙 코어 지도 버튼을 최소48px로 확대하고 고체 용기의 드래그 물체와 터치 지점 겹침을 줄였다. 짧은 화면의 고체 실험 공간은 내부 스크롤을 허용한다.
4. exFAT 외장 SSD가 만드는 AppleDouble `._*` 파일을 테스트 대상에서 제외했다. 실제 테스트 파일은 그대로 실행한다. 메타파일 삭제나 영구삭제는 하지 않았다.
5. 기존 그림·배경·걷기 연출·CC0 효과음·합성 BGM·개념영상/자막을 유지했다. 새 이미지로 시각 요소를 늘릴 필요가 없었으며 새 유료 호출/모모 음성 생성은 하지 않았다. 신규 NPC 음성 품질이 개선됐다고 주장하지 않는다.

## 학습·스테이지 중복 점검

프로젝트에 기재된 성취기준은 [4과05-01], [4과05-02], [4과05-03]이다. 기존 설정의 2022 개정 교육과정/교육청 자료 출처를 유지했다. 이번 회차에 공식 원문을 새로 확보하여 문구를 재검증하지는 않았으므로 학교 최종 편성 때 원문 대조가 필요하다.

| 활동 | 고유 조작과 학습 증거 | 반복 여부 판단 |
|---|---|---|
| S01·S02 | 우산 부품 관찰 → 재료와 관찰 근거 연결 | 같은 우산이지만 관찰과 근거 적용이 달라 필요한 연계 |
| S03·S04 | 같은 조건으로 시료 비교 → 창/보호대에 쓰임 설명 | 실험 결과를 새 의뢰에 적용, 단순 재풀이 아님 |
| S05·S06 | 고체 용기 이동 → 물 기울여 붓기·원래 용기로 복귀·모래 확대 | 상태별 조작·오개념이 다름. 최초 예상과 수정 답 분리 보강 |
| S07·S08 | 뒤집힌 컵 → 같은 깊이·방향에서 배출구만 변경·펌프 | 통제 조건 비교로 의도된 연속 활동 |
| S09·S10 | 요구조건·재료·관찰 근거 설계 → 비/빛/충격 시험·수정 | 이전 결과를 발명에 통합. 설계 개정 전 시험 결과는 새 설계의 통과로 인정하지 않음 |

물높이와 물의 양을 구분하며, 흘리지 않은 가상 조건에서 보존을 설명한다. 모래알은 고체이며 흘러 보이는 집합의 모습만으로 액체로 분류하지 않는다. 컵의 공기 실험에서 깊이80·방향을 같게 하고 배출구만 바꾼다. 실제 실험을 대체하거나 모든 재료의 성질을 단정하는 게임으로 안내하지 않는다.
