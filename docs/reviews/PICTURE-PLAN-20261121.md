# 물질 공방 대작전: 글로만 된 곳을 그림으로 (디자인 고도화 계획, 2026-11-21)

목표: 초등 3학년이 글을 다 읽지 않아도 무엇을 고르고 어디에 놓는지 그림으로 바로 알게 한다. 글은 지우지 않고 **그림 + 글**로 둔다(목소리·자동 검사·읽기 도구가 글에 묶여 있다).

## 원칙

- **답을 그림이 알려 주지 않게.** 재료 카드는 「재료 덩어리」(천 조각·금속판·나무토막)로 그리고, 정답 부품을 닮은 모양(우산 살 같은 막대, 손잡이 모양)은 피한다. 「물이 스며드는 휴지」처럼 성질 자체가 답인 보기는 물건만 그리고 성질은 그리지 않는다.
- **같은 화풍 한 묶음.** 한 문제의 그림은 GPT 이미지 한 장에 한 줄로 그려 `scripts/prepare-picture-cards.mjs`로 자른다(색·빛·외곽선이 같아진다). 앞서 만든 그림을 참고로 넣는다.
- **크게, 한눈에.** 카드는 그림 위·이름 아래(`DragBoard variant="cards"`), 고르기 보기는 그림 왼쪽·글 오른쪽(`CHOICE_ART`). 폰 가로(높이 520 이하)에서는 그림을 줄인다.
- **끌기는 아이 손에 맞게.** 끄는 그림은 손가락 한가운데, 지금 놓일 칸은 초록으로 켜지고, 칸 사이 틈이나 칸 바로 밖에서 놓아도 가까운 칸으로 들어간다(32px).
- **확인.** 세 화면 크기 + 폰 가로 스크린숏, 학생 완주 검사, 배치 검사(305화면), 권리 장부·CREDITS 한 줄씩.
