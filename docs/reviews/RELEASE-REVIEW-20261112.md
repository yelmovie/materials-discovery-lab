미완성 제작 부품·시험 중간 상태는 새로고침하면 다시 시작하고, 완료 납품과 학습 기록은 저장돼. 일부 짧은 화면 제어는 44px이고 제어 간격이 8px보다 좁아. 손상 JSON은 원문 복구본을 보존하고 새 기록으로 시작해. Jua 글꼴·미사용 Three.js 후보·Phaser 대형 청크·반복 레이아웃과 blur의 저사양 비용은 기존 성능 주의 항목으로 남아 있어.

기존 게임 탭을 모두 닫고 공개 주소를 다시 열면 새 버전이 적용돼. 열린 수업을 유지하기 위해 새 서비스워커는 대기해. `/index.html` 리다이렉트 회귀와 구·신 캐시 교체는 Chrome에서 확인했어. [업데이트 회귀](science-20261112/offline-redirect-regression.json)

작업 파일·생성 원본·빌드·시험 프로필·임시 데이터는 확인한 외장 T7 SSD에 두었어. 이미지 생성 도구의 임시 원본은 허용된 예외에 따라 외장 복사와 대조 후 해당 파일만 삭제했어. Codex 앱 자체의 저장 설정을 이동하는 작업은 이번 범위에 포함되지 않았어.
