## 실행 환경과 오류 기록

- 기본 읽기 샌드박스에서 Git 버전 조회의 `/tmp/xcrun_db` 캐시 생성, heredoc 임시파일 생성, 프로세스 조회가 차단됐다. 해당 기본 호출을 그대로 반복하거나 권한 설정을 바꾸지 않았다. 승인된 격리 작업은 도구의 로컬 실행 권한으로 수행했다.
- 시스템 Python 3.9.6의 한글 stdin 파싱 실패로 첫 수정 스크립트는 실행되지 않았다. `git diff`가 비어 있음을 확인한 뒤 저장소 런타임인 Node로 수정했다.
- 첫 수정 중 JSX 닫힘 오류를 타입 검사가 잡았고, 수정 후 테스트와 빌드가 통과했다.
- 테스트 참조 로더의 사용하지 않는 Vite 의존성 탐색이 종료 시 경고를 냈다. 검증 도구에서만 탐색을 끄고 재실행했다.
- 성취 카드의 의도된 흔들림 때문에 Playwright의 정지 대기가 시간 초과됐다. 표시와 가림 여부를 확인한 실제 포인터 클릭으로 검사했다. 이어서 6장 완성 축하의 ‘멋져요!’ 단계가 누락돼 PNG 다운로드가 시작되지 않은 것을 확인하고 검사에 그 단계를 포함했다. 제품의 보상 연출을 바꾸거나 가려진 버튼을 강제 클릭하지 않았다.
- 기본 Python에는 Playwright가 없어, Node Playwright 1.56.1만 이 clone의 `.tmp/browser-qa`에 임시 설치했다. 프로젝트 의존성·잠금파일·전역 설치·사용자 Chrome 프로필은 바꾸지 않았다.

- 실행 중 로컬 서버·검사 세션이 종료된 적이 있었다. 동일 Macmini가 계속 attached 상태임과 프로세스 종료·완료 산출물을 확인했다. 1280 결과를 보존하고 이 작업의 서버 및 미완료 1024 검사만 다시 실행했다. 기기 재시작은 하지 않았다.
- 별도 회귀의 나무 소재 선택자와 워커 준비 대기를 실제 전체 이름 및 실험 화면 진입 흐름에 맞췄다. 준비 대기는 async poll의 Promise가 아니라 실제 controller 획득을 확인한다.

## 검증의 한계

- 데스크톱 Mac의 격리 headless Chrome에서 화면 크기를 맞춘 검사다. 실제 iPad·Android 태블릿이나 Safari·전자칠판 성능·터치 검증이 아니다.
- 실물 프린터 출력, 실제 학교 네트워크, 40분 학생 수업·학습 효과 검증은 수행하지 않았다.
- 기존 3D·이미지·음원·영상 에셋은 유지했다. 신규 콘텐츠 제작이나 전면 리디자인은 하지 않았다.
