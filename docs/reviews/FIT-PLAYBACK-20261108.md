# 조작 활동 한 화면 배치·자동재생

2026-11-08. 이번 변경은 이전 `RESPONSIVE-UPGRADE-20261108.md`의 스크롤 허용 방식을 대체한다. 5개 스테이지의 10개 조작 활동을 화면 높이 안에 배치하고, 실험 과정에 자동재생을 추가했다.

실험 장면이 남은 공간을 채우고 제목·탐구 순서·조작 버튼은 독립된 행을 쓴다. 넓은 화면은 실험과 판단 도구를 나란히, 휴대폰 세로 화면은 위아래로 배치한다. 교사용 이동 버튼도 다음 활동 버튼과 겹치지 않는다. 기본 활동의 문서·실험·도구 영역에는 가로·세로 스크롤이 없다.

중복된 부품 선택 행, 재료 미리보기, 선택 시료 이름, 실험 실행 버튼과 반복 안내를 정리했다. 긴 관찰 설명·예상 기록·설계 요구·근거 전문·시험 결과는 버튼으로 열어 확인한다. 예상·근거·정답의 실제 판단은 그대로 학습자가 한다. 다음에 할 수 있는 실행·기록·이동 버튼은 테두리와 명확한 문구로 강조한다. 상태 알림은 실험 위를 가리지 않고 상단 제목 자리에서 잠시 보여준다.

| 활동 | 자동재생과 수동 판단의 구분 |
| --- | --- |
| S01 우산 관찰 | 부품을 차례로 보여주고 관찰을 기록한다. 적용 문제 답은 선택하지 않는다. |
| S02 재료 연결 | 재료 배치와 근거 연결이 판단 활동이므로 자동재생 버튼을 두지 않는다. |
| S03 시료 시험 | 고른 시료로 실험한 뒤 멈춘다. 관찰 결과 문장과 기록은 수동이다. |
| S04 쓰임에 맞는 재료 | 재료·성질·근거를 학습자가 판단하므로 자동 선택 기능을 두지 않는다. |
| S05 고체 | 예상한 뒤 세 용기로 토막을 옮긴다. 결론은 수동이다. |
| S06 액체 | 예상한 뒤 실제 물의 양을 보존하며 세 용기로 순서대로 옮긴다. 물의 결론을 직접 고르면 모래알 확대도 재생할 수 있다. 물·모래 결론은 각각 직접 고른다. |
| S07 닫힌 컵 | 휴지를 확인하고 컵을 넣어 관찰 기록을 남긴다. 적용 문제는 수동이다. |
| S08 열린 컵·주머니 | 배출구를 열어 관찰한다. 비교 판단은 수동이며, 판단 후 펌프 과정을 재생할 수 있다. |
| S09 설계 | 재료·설계 요구·관찰 근거를 직접 판단하므로 자동재생 버튼을 두지 않는다. |
| S10 시험 | 현재 설계의 비·빛·충격 시험을 순서대로 실행한다. 적용 문제는 수동이다. |

자동재생은 0.5·1·1.5·2배 속도를 지원하고, 재생 도중 속도를 바꿀 수 있다. `멈추기` 또는 수동 조작으로 중단하며, 다른 탭으로 가거나 활동을 벗어나면 대기와 실행을 취소한다. 물은 멈춘 양에서 이어가고, 펌프는 중단 후 수동으로도 이어갈 수 있다. 중단한 시험의 결과가 나중에 저장되는 것을 막았다. 저장 스키마·정답 판정·해금 규칙은 바꾸지 않았다.

검사 크기는 1920×1080, 1366×768, 1280×800, 1024×600, 915×412, 740×360, 390×844이다. 문서뿐 아니라 `.activity-grid`, `.workspace`, `.tools`의 실제 스크롤 크기와 모든 활성·비활성 버튼의 잘림을 검사했다. 글자는 실제 텍스트 행의 경계를 측정하고, 버튼 중심점의 실제 가림과 44px 터치 영역도 확인했다. 이전 검사처럼 스크롤 가능한 패널이라는 이유로 잘림을 제외하지 않는다.

작은 화면의 학생 진행 검증은 예상 전, 자동재생 후, 관찰 기록 후, 답 선택 후와 채점 후까지 포함한다. S03 중단 후 준비 상태 복귀, S06 멈춤·슬라이더 입력에 따른 실제 물 이동 정지, S08 펌프 중단 후 조작 가능 상태, S10 중단 후 늦은 결과 저장 방지를 확인했다. 자동재생 전후에 예상·처음 예상·적용 문제 답·설계 판단이 같은지도 비교했다.

작은 가로 화면에서 긴 관찰 결과가 나온 뒤에도 답과 버튼이 남도록 S03 도구 패널의 폭을 확보하고, 실행 버튼은 짧은 문구와 전체 접근성 이름을 함께 사용했다. 최종 빌드의 소스 지문은 `361a57b243469207f16177df264e41db5ae9c325d0abbcbc8be02352d43c0dcf`이다.

검사 예외는 스크린리더 전용 숨김 문구와, 현재 용기 안에 놓이는 나무토막의 의도한 조작 영역 겹침이다. 선택적으로 여는 상세 설명 대화상자는 기본 실험 화면과 구분한다. 실제 iPad·Android 터치와 Safari는 미실측이다.

배치 전수 검사는 캐시된 이전 화면을 피하려고 서비스 워커를 차단한 새 브라우저에서 실행한다. 이 조건의 시작 화면에는 오프라인 준비 안내가 잠시 표시될 수 있다. 실제 서비스 워커를 허용한 별도 검사에서는 오프라인 새로고침 뒤 S01의 세 부품 자동 관찰까지 확인했다 (`.tmp/fit-offline-diagnostic.log`).

새 공통 규칙은 마지막에 읽는 `src/stage-fit.css`에 있고, 자동재생의 등록·중단·정리는 `src/components/ExperimentPlayback.tsx`가 담당한다. 학습 판단은 기존 활동과 도메인 코드가 담당한다. 새 패키지나 외부 생성 이미지는 추가하지 않았다.
