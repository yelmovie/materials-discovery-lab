# 개념 영상 · 조작 · 교실 화면 개선 검증

2026-10-22, 로컬 프로젝트 기준. 공개 배포는 하지 않았어.

## 적용한 변화

- 다섯 스테이지의 활동 10개에 각각 9초 개념 모션 영상 적용. 완료 → 개념 정리 → 다음 활동/복구 보상으로 연결하고, 탐구 뒤 다시 보기도 제공해.
- SVG → sharp → FFmpeg로 WebM·MP4·마지막 장면 포스터 제작. 세 파일 모두 합쳐 1,067,082바이트. 큰 DOM 자막, 정지·이어 보기·재시작·건너뛰기, 동작 줄이기, 파일 실패 대체 설명을 제공해.
- 기존 다람쥐 모루를 지도 동행·모든 활동의 진행별 힌트 3단계·영상 설명에 일관되게 연결했어.
- 돋보기 끌기, 부품/재료 끌어 연결하기, 분류 카드 배치, 나무토막 이동, 기울기와 연속 붓기, 공기 컵 이동·배출구·펌프를 적용했어. 끌기 대신 카드와 칸을 차례로 누르는 방법도 제공해.
- 설계 재료를 바꾸면 몸체 색·나뭇결·창 투명도·보호대가 바로 바뀌는 보관함 모형을 추가했어. 관찰 근거와 현재 설계의 시험 판정은 기존 도메인 로직을 사용해.
- 팝업을 뷰포트 중앙으로 고정하고, 화면 폭별 글자·여백·간격·패널 너비를 맞췄어. 확인한 예상·요구 조건·시험 결과는 접어 둘 수 있어. 의뢰의 확인과 진행 버튼은 하단의 같은 자리를 사용해.
- Kenney Interface Sounds의 CC0 효과음 8종을 적용하고 원본·라이선스·파일 매핑을 보존했어. 영상 중 BGM/효과음 중단, 음소거·개별 설정, 동시 효과음 1개 처리를 적용했어.
- 영상·효과음을 오프라인 캐시에 포함하고, 캐시된 영상의 Range 요청과 206/416 응답을 처리해.

체크박스는 실제로 누를 수 있는 감싸는 label 영역을 측정했어. 접힌 details의 숨은 조작은 보이는 버튼으로 세지 않았어. 아주 낮은 가로 화면에서는 긴 근거를 패널 내부에서 최대 약 180px 스크롤해. 화면 전체를 길게 스크롤하지 않아도 주요 조작과 하단 진행 버튼에 접근할 수 있어.

React 품질 점검에서는 훅 의존성, 재생·포인터·타이머 정리, 키보드 대체, 접근성 이름과 상태, 무음/동작 줄이기, 무거운 씬의 지연 로딩을 확인했어. 의뢰 전환의 하단 버튼 상태는 화면이 그려지기 전에 맞춰 이전 행동이 잠깐 노출되지 않게 했어.

## 남은 확인

실제 태블릿의 터치 감도, 전자칠판을 멀리서 보는 가독성, 학생의 활동 이해도·학습 성취, 30명 동시 교실망은 실기기로 확인하지 않았어. 이번 자동 검수와 브라우저 플레이 결과를 실제 수업 검증으로 표현하지 않아. 보관함은 재료가 반영되는 SVG 과학 모형이고 GLB 3D 모델은 아니야. 기존 Phaser 청크의 크기 경고는 빌드에 남아 있어.
