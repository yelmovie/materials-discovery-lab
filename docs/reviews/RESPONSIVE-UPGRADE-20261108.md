# 스테이지 반응형·학습 시각화 개선 기록

2026-11-08 · 로컬 소스 반영 완료

후속 요청으로 스크롤 허용 방식은 `FIT-PLAYBACK-20261108.md`의 한 화면 배치·자동재생 방식으로 대체됐다. 아래 내용은 이전 검수 기록이다.

10개 활동의 안내, 실험 그림, 조작 도구와 관찰 결과가 서로 다른 공간을 사용하도록 수정했다. 공통 레이아웃은 한 담당자가 관리하고, 고체·공기 / 재료·액체 / 우산·발명 활동을 병렬로 구현한 뒤 실제 Chromium에서 통합 검증했다.

| 활동 | 반영한 개선 |
| --- | --- |
| S01 물체 관찰 | 우산 천·금속 살·나무 손잡이가 연결된 SVG 모형, 부품 강조와 재료 질감, 그림과 분리된 조작 도구 |
| S02 부품과 재료 | 재료 카드와 관찰 기록 분리, 최대 확대에서도 48px 부품 마커 유지, 돋보기 드래그 뒤 의도하지 않은 확대 방지 |
| S03 성질 실험 | 고무의 변형·복원, 빛 투과와 뒤쪽 표시, 물방울 흡수, 눌렀다 놓는 과정을 SVG로 표현하고 설명은 DOM 텍스트로 분리 |
| S04 쓰임과 재료 | 놓은 재료가 즉시 반영되는 보관함, 관찰창·보호대의 목적 표시, 모형 상단이 스크롤 영역 밖으로 밀리는 현상 수정 |
| S05 고체 | 같은 크기 나무토막과 점선 윤곽, 서로 다른 용기, 현재 위치·관찰 완료 표시, 장면 기준 드래그 좌표 |
| S06 액체·모래 | 물의 양에 따른 수면, 처음 컵 기준선, 총량·이동 순서의 별도 행, 모래 더미와 알갱이 확대 비교 |
| S07 닫힌 컵 | 마른 휴지·물 표면·남은 공기 공간 표시, S08 완료 후 재방문해도 닫힌 실험 조건으로 표시 |
| S08 열린 컵 | 배출구, 젖은 휴지, 공기 배출과 물 유입을 구분하는 표시 |
| S09 발명 설계 | 재료 질감과 투명 관찰창 내부 표현, 선택 부품 강조, 체크 아이콘과 선택지 본문 분리 |
| S10 시험 | 현재 설계의 시험 통과 수, 시험별 상태와 관찰 모형의 구분 |

공통 레이아웃은 긴 한글 문구에 `min-width: 0`과 줄바꿈을 적용하고, 한 글자짜리 재료 카드에도 최소 48px 폭을 확보했다. 그림과 도구가 함께 줄어들며 덮이는 현상을 방지하도록 최소 높이와 flex 축소 규칙을 조정했다. 작은 화면은 문서 스크롤로 전체 내용을 볼 수 있고, 교사용 버튼·활동 버튼·상단 메뉴가 실험 내용 위에 고정되어 가리는 것을 피했다. 활동이 바뀌면 새 제목 위치로 스크롤을 복원한다.

저장 스키마, 정답 판정과 해금 규칙은 유지했다. 추가 의존성이나 외부 생성 에셋은 사용하지 않았다.

반응형 검사 크기: 1920×1080, 1366×768, 1280×800, 1024×600, 915×412, 740×360, 390×844. 기본 탐구와 적용 문제를 검사하고, 4가지 크기에서 최대 확대, 돋보기 드래그, 4종 재료 실험의 관찰 결과, 고체 이동, 물 이동 중간 상태, 모래 확대, 닫힌 컵·열린 컵 재방문을 추가 확인했다.

학생 진행 검증은 실제 버튼·포인터로 탐구 → 적용 문제 → 개념 영상 → 다음 활동 → 보고서 → 코어 → 인증서를 진행했다. 영상 재생·일시 정지·재개, 영상 로딩 실패 시 설명과 계속하기 제공, 저장 후 새로고침 복원을 확인했다. 시연 모드에서 학생 완료 기록이 생성되지 않는 것도 확인했다.

스크린샷은 `responsive-20261108/complete-final/`, 배포용 빌드 스크린샷은 `responsive-20261108/release/`, S04의 최종 스크린샷은 `responsive-20261108/assignment-release/`에 있다. 통합 중 발견한 실패 기록은 별도 폴더에 보존했으며 위 표가 최종 확인 근거다.

**검사 범위와 예외**

- 스크롤 영역 안의 콘텐츠는 스크롤로 접근할 수 있으므로 처음 화면 밖에 있다는 이유만으로 오류로 세지 않았다.
- 고체 실험의 나무토막은 현재 용기 위에 놓이는 조작 대상이다. 같은 조작 영역인 용기 버튼과 토막의 의도한 겹침은 버튼 가림에서 제외했다.
- 창 크기를 조절한 Chromium과 마우스·키보드 입력으로 확인했다. 실제 iPad·Android 터치, 학교 기기 성능과 Safari는 미실측이다.
- 배포용 화면의 일부 초기 스크린샷에는 기존 오프라인 준비 알림이 포함돼 있다. 이 알림은 7초 뒤 사라지고 포인터 입력을 차단하지 않는다.
- Vitest 워커 종료 지연과 기존 Phaser 청크 크기 경고가 있었으며 테스트·빌드는 정상 종료했다.
