# 제작·조립 루프 1차 구현

## 목표와 범위
기존 5공방·10탐구·20개 적용 문제·학습기록·최신 반투명 UI를 유지한다. 각 공방 두 번째 활동에서 탐구를 끝내면 주 행동이 주문 제작으로 연결된다. 신규 5개 미션은 부품 선택/드래그 → 조립 → 기능 시험 → 부품별 실패 원인 → 수정 → 주민 납품으로 구성한다. 기존 학습 경로와 완료 기록은 잠그지 않는다. 전면 장르 전환이나 기존 10탐구 폐기가 아니다.

## 미션/학습 대응
- S02 작은 지붕: 부품 역할, 물 스밈과 형태 유지. 지붕/받침 두 부품을 조립하고 비/하중 표현을 관찰.
- S04 전시 상자: 투명성과 눌렸다 복원되는 성질. 창/모서리를 교체하고 기능 비교.
- S06 운반대: 고체 형태 유지, 액체 용기와 양. 판/컵 조합에 따라 누수 표현.
- S08 공기 깃발: 공기의 이동. 막힘과 관 끝 방향을 바꾸며 날개 작동.
- S10 최종 주문: 방수/투명/복원 성질을 종합한 세 부품 시험.

## 기술
maker.ts의 순수 판정과 MakerMission UI를 분리. 정답뿐 아니라 부품별 실패를 유지해 재시도하며 시험 중 중복 실행 방지. 타이머 해제, 동작 줄이기 지원. 클릭 후 슬롯 선택은 드래그의 동등 대안. 모든 타깃은 44px 이상을 목표. 기존 저장키에 deliveries만 추가하고 오래된 저장은 빈 기록으로 마이그레이션. reducer가 탐구 준비와 현재 화면, 부품 판정을 검증하며 시연 기록은 학생 기록과 분리.

## 과학 표현 경계
구체 시료/조건의 축약 모형이다. 재료 이름 하나로 실제 제품 안전/성능을 보장하지 않는다. 공기 흐름의 흰 점은 모형임을 표시한다. 압력·힘 수치를 실제 예측으로 제시하지 않는다. 부품 조합은 학습성질 재사용을 위한 제한된 설계 공간이며 실물 설계 검증이 아니다.

## 남은 범위
기존 지도/코어 복구 서사는 유지한다. 신규 제작은 각 공방에서 연결되는 5개 미션이며 모든 기존 탐구를 독립 제작 퍼즐로 바꾼 것은 아니다. 실제 교실 학습 효과와 실물 태블릿은 별도 확인.

## 검증 결과
- 단위 테스트 60개 통과(기존 48 + 신규 제작/저장 검증 12), TypeScript/프로덕션 빌드 통과.
- 기존 탐구/문제 60화면, 1280×800·873×580·390×844에서 오류/가로 넘침 0.
- 신규 5미션 × 4화면(1280×800·1024×768·873×580·390×844), 실패 조합→부품 수정→성공→납품 20케이스 통과. 페이지 오류 0, 활성 버튼 중심 히트 테스트/가로 넘침 확인. 낮은 가로 화면의 결과·시험 버튼 겹침을 발견하고 고정 최소 높이와 세로 스크롤로 수정.
- 브라우저 시연 모드에서 수행한 자동 검사이며 자연 학생 진행 전체나 실물 터치 기기 검증과 동일하지 않다. 학생 저장 마이그레이션/잘못된 기록 배제는 단위 테스트로 별도 확인.
